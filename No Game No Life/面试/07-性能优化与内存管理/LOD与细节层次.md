## 🎯 一句话结论（自测用）
> LOD（Level of Detail）按模型距离摄像机的远近，使用不同面数的模型渲染，降低 GPU 负载。优点：减少顶点和三角面处理量、降低 GPU 开销。缺点：增加了内存（需要存储多套模型）、需要美术额外制作 LOD 级别或使用自动减面工具。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **LOD 是什么**：根据物体与摄像机的距离，动态切换不同面数的模型。近处用高模，远处用低模或直接剔除。
2. **工作流程**：
   - 美术制作 LOD0（最高精度）、LOD1、LOD2...（或使用自动化减面工具）
   - Unity 中使用 LOD Group 组件配置各距离阈值
   - 运行时由引擎根据距离自动切换
3. **优点**：
   - 减少远处物体的顶点数和三角面数，降低 GPU 顶点/片元处理开销
   - 配合视野距离剔除（Frustum Culling）效果更佳
   - 在大世界/开放世界场景中效果显著
4. **缺点**：
   - 增加内存/包体（需要存储多套模型）
   - 美术工作量增加
   - LOD 切换时可能有视觉跳变（可以用抖动过渡 Dithering/Cross-Fade）
5. **QEM 简化算法**（二次误差度量）：自动减面算法，通过迭代合并边来减少面数，保证简化后的模型与原模型在视觉上最接近。

## 🔍 详细解析

### Unity LOD Group
- 在模型 Prefab 上添加 LOD Group 组件
- 配置 LOD0（0%~质量最高）、LOD1（距离X%）、LOD2（距离Y%）、Culled（距离Z%）
- 可手动指定每级使用的 Mesh，或使用自动减面
- Cross-Fade 设置过渡方式

### LOD 不只是模型
- **Shader LOD**：远处物体使用更简单的 Shader（如去掉法线贴图、高光计算）
- **动画 LOD**：远处角色降低骨骼更新频率
- **Shadow LOD**：远处物体不投射实时阴影

### QEM 简化算法原理
- 为每条边计算折叠后的误差（二次误差度量）
- 每次选择误差最小的边进行折叠
- 迭代直到达到目标面数
- 结果：在面数大幅减少时仍保持较好的视觉质量

### LOD 与合批的关系
- LOD 切换导致模型改变，可能打破合批
- 同级 LOD 的不同物体之间仍可合批
- 建议：保证同级 LOD 的物体使用相同材质

## 💬 面试官常见追问
- **LOD 增加了多少内存？** → 通常 LOD1 面数是 LOD0 的 50%，LOD2 是 LOD0 的 25%。总内存约为原始的 1.75 倍
- **怎么避免 LOD 切换的视觉跳变？** → Cross-Fade（抖动过渡）、增加 LOD 级别数量、调整切换距离
- **移动端 LOD 级别多少合适？** → 通常 3 级（LOD0 + LOD1 + Culled），过多级别增加内存和切换判断开销
- **QEM 和 Mesh Optimizer 是什么关系？** → QEM 是一种算法思路，Unity Mesh Optimizer 等工具实现了类似算法

## ⚠️ 我曾经的误区 / 网上常见错答
- 误区：LOD 只省 GPU 不费内存。实际上多套模型增加内存和包体
- 误区：LOD 级别越多越好。过多级别增加切换判断开销，移动端 2-3 级即可
