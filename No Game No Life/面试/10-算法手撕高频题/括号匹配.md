## 🎯 一句话结论（自测用）
> 左括号入栈，右括号检查栈顶是否匹配。最后栈为空则匹配。O(n) 时间 O(n) 空间。核心是 `unordered_map<char,char>` 存储配对。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. 遍历字符串，左括号 `([{` 入栈
2. 遇到右括号，检查栈是否为空、栈顶是否与右括号匹配
3. 不匹配返回 false，匹配则弹出栈顶
4. 遍历完后栈为空则返回 true
5. 时间复杂度 O(n)，空间复杂度 O(n)

## 🔍 详细解析

### C++ 标准实现
```cpp
bool isValid(string s) {
    stack<char> st;
    unordered_map<char, char> pairs = {
        {')', '('},
        {']', '['},
        {'}', '{'}
    };
    
    for (char c : s) {
        if (pairs.count(c)) {  // 右括号
            if (st.empty() || st.top() != pairs[c])
                return false;
            st.pop();
        } else {  // 左括号
            st.push(c);
        }
    }
    return st.empty();
}
```

### Csharp 版本
```csharp
public bool IsValid(string s)
{
    var stack = new Stack<char>();
    var pairs = new Dictionary<char, char>
    {
        {')', '('},
        {']', '['},
        {'}', '{'}
    };

    foreach (char c in s)
    {
        if (pairs.ContainsKey(c))
        {
            if (stack.Count == 0 || stack.Pop() != pairs[c])
                return false;
        }
        else
        {
            stack.Push(c);
        }
    }
    return stack.Count == 0;
}
```

### 常见变体
**只有一种括号（只需计数）**：
```cpp
bool isValidSimple(string s) {
    int count = 0;
    for (char c : s) {
        if (c == '(') count++;
        else if (c == ')') count--;
        if (count < 0) return false;  // 右括号多于左括号
    }
    return count == 0;
}
```

**带通配符的括号匹配（LeetCode 678）**：
`*` 可以表示 `(`、`)` 或空字符串。需要记录未匹配左括号数量的可能范围。

**最长有效括号（LeetCode 32）**：
```cpp
int longestValidParentheses(string s) {
    int maxLen = 0;
    stack<int> st;
    st.push(-1);  // 基准索引
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == '(') {
            st.push(i);
        } else {
            st.pop();
            if (st.empty()) {
                st.push(i);  // 新的基准
            } else {
                maxLen = max(maxLen, i - st.top());
            }
        }
    }
    return maxLen;
}
```

## 💬 面试官常见追问
- "如果括号类型很多（如 HTML 标签），如何处理？" -> 哈希表驱动的方式天然支持，只需要扩展 pairs 字典
- "不匹配有哪几种情况？" -> 1) 右括号多余（栈空时遇到右括号）2) 类型不匹配 3) 左括号多余（遍历完后栈非空）
- "能否不用栈？" -> 只有一种括号时用计数；多种括号必须用栈（需要记录类型）

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：遇到右括号时忘了检查栈是否为空就直接 `st.top()`。空栈访问会崩溃
- **误区**：只检查了左右括号数量相等，没检查顺序。`)(` 数量相等但不合法
- **误区**：遍历完后直接返回 true。必须检查 `st.empty()`
