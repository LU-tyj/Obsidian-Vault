_Simulate a collection of independent objects by telling each to process one frame of behavior at a time._

## 1 Keep in Mind
**使用情境**：
- 你的游戏中含有一系列对象或系统需要同步地运转。
- 各个对象之间的行为几乎是相互独立的。
- 对象的行为与时间相关。

**注意**：
1. 将游戏操作分布到每一个帧（比如你可以使一个ai在一个update中先左走再右走，但最好能在一个帧里经过判断后只左走/右走一步；
2. 使用 [[2.6 State Pattern]] 中提及的状态系统来存储帧之间的状态；
3. 所有的GO都在每帧中进行，但是没有同步，通过顺序执行的方式来进行解决。如果出现有序性问题，可以使用 [[3.1 Double Buffer]] 中提到的双缓冲模式（update然后swap）
4. 更新GO列表时需要谨慎，以免出现遍历遗漏的问题

>update 方法如果使用代理类的话（比如状态系统），可以存储在代理类中
>每次调用时用 `state->update()`即可

## 2 Samples
其实在unity中非常常见所以就不细说了，只讲一个根据时间进行位置的更新
```cpp
void Skeleton::update(double elapsed)
{
  if (patrollingLeft_)
  {
    x -= elapsed;
    if (x <= 0)
    {
      patrollingLeft_ = false;
      x = -x;
    }
  }
  else
  {
    x += elapsed;
    if (x >= 100)
    {
      patrollingLeft_ = true;
      x = 100 - (x - 100);
    }
  }
}
```
这里就是传入了`elapsed`，根据更新帧率来位移。
