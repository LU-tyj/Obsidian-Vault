## 🎯 一句话结论（自测用）
> 光栅化是将几何图元（三角形）转换为屏幕片元（像素样本）的过程。核心步骤是三角形设置 -> 三角形遍历（判断哪些像素被三角形覆盖）-> 插值顶点属性。判断点是否在三角形内常用重心坐标法或叉乘法。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **光栅化的基本流程**：
   - 三角形设置：根据三个顶点的屏幕坐标，计算出三角形的边方程（Edge Functions）
   - 三角形遍历：判断屏幕上哪些像素的中心位于三角形内部，生成片元
   - 属性插值：对三角形的顶点属性（颜色、法线、UV坐标等）用重心坐标进行插值，赋给每个片元
2. **判断点在三角形内**（网易高频手撕/口述）：
   - **叉乘法**：分别计算 P 到每条边的叉乘方向 `(AB × AP)`, `(BC × BP)`, `(CA × CP)`，如果三个叉乘结果**同号**（全正或全负），则点在三角形内
   - **重心坐标法**：解 `P = αA + βB + γC`，如果 α, β, γ 都 >= 0 且 α+β+γ = 1，则点在三角形内
3. **三角形遍历的优化**：
   - AABB 包围盒：只检查三角形包围盒内的像素
   - Tiled 方式：以 tile 为单位批量处理（移动端 TBR 架构的精髓）

## 🔍 详细解析

**叉乘法判断点在三角形内的推导**：

对于三角形 ABC 和待测点 P，以顶点顺序 A->B->C 为基准：
- 计算 `cross(B-A, P-A)`: 若 >0，P 在边 AB 的左侧
- 计算 `cross(C-B, P-B)`: 若 >0，P 在边 BC 的左侧
- 计算 `cross(A-C, P-C)`: 若 >0，P 在边 CA 的左侧

三项都 > 0（按逆时针顶点序）或都 < 0（按顺时针顶点序），则 P 在三角形内。

**重心坐标（Barycentric Coordinates）的应用**：
- 判断点是否在三角形内（三个分量都 >= 0 且在 [0,1] 范围）
- 插值顶点属性：`interpolated_value = α * value_A + β * value_B + γ * value_C`
- 注意：透视投影下不能直接线性插值，需要做透视校正插值

**光栅化中的走样问题**：
光栅化的离散采样本质上就是"采样"，将连续几何离散化到像素网格，必然产生锯齿（Aliasing）。需要 [[抗锯齿技术]] 来缓解。

## 💬 面试官常见追问
- "如果三角形非常大，遍历所有在 AABB 内的像素效率很低，有什么优化？" -> 使用 Tiled 方式，结合早期 exit 的分块扫描
- "为什么要做透视校正插值？" -> 在透视投影下，三角形内部属性（如 UV）在屏幕空间不是线性变化的。直接用屏幕空间线性插值会导致纹理扭曲。需要先计算 `1/w` 的线性插值，再反推正确属性值

## ⚠️ 我曾经的误区 / 网上常见错答
- 误区：光栅化就是"画三角形"。实际上光栅化的核心是离散采样和属性插值，不只是画图
- 误区：叉乘法判断点在三角形内需要规范化向量。叉乘只需方向判断（看正负），不需要单位向量
