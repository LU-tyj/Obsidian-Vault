# 网易互娱面试情报

## 一、面试流程

### 标准流程（校招/实习）
```
网申/内推 -> 笔试 -> 一面（技术基础面）-> 二面（深度技术面）-> HR面 -> OC/Offer
```

### 各轮说明

| 轮次   | 时长       | 形式    | 内容                           |
| ---- | -------- | ----- | ---------------------------- |
| 笔试   | 2-3 小时   | 在线 OJ | 3-4 道编程题（DP/树/图/贪心），杭电 OJ 风格 |
| 一面   | 40-60 分钟 | 电话/视频 | C++/Csharp/Unity 基础 + 算法手撕   |
| 二面   | 50-90 分钟 | 视频/线下 | 图形学深挖 + 场景题 + 项目深挖 + 系统设计    |
| HR 面 | 20-30 分钟 | 电话/视频 | 文化匹配、职业规划、游戏理解               |
| OC   | 3-5 个工作日 | -     | 特殊情况下可能无 HR 面直接发 offer       |

### 变体流程
- **AB 面（雷火特色）**：同一天或连续两天安排两轮技术交叉面，节奏快
- **总监面**：二面后增加一轮项目组大佬面，30-50 分钟
- **交叉面**：另一项目组大佬面，侧重底层原理与算法优化

### 时间线参考
| 阶段 | 间隔 |
|------|------|
| 投递 -> 笔试 | 1-2 周 |
| 笔试 -> 一面通知 | 约 1 周 |
| 一面 -> 二面 | 1-2 周 |
| 二面 -> HR 面 | 约 1 周 |
| HR 面 -> OC | 3-5 个工作日 |

## 二、部门差异

### 网易雷火（杭州）
- **流程**：AB 面 + 交叉面 + 主管面 + HR 面（3-5 轮）
- **技术栈侧重**：Lua（极高频）、网络同步方案（帧同步 vs 状态同步，几乎必问）、C++ 内存模型、图形学深度
- **面试风格**：追问式，每个回答都可被继续深挖，直到触及知识边界
- **代表作**：《逆水寒》《永劫无间》
- **难度**：极高，对基础深度要求最严苛

### 网易伏羲（杭州）
- **定位**：AI 实验室 + 游戏研发
- **技术栈侧重**：除常规客户端知识外，可能涉及 AI/ML 基础
- **面试风格**：方向侧重 AI，面经公开较少

### 网易互娱（广州/上海/杭州）
- **流程**：标准 2 轮技术 + 1 轮 HR（3 轮）
- **技术栈侧重**：C++/Unity/图形学/算法均衡覆盖
- **面试风格**：一面友好引导型，二面深度压力型
- **代表作**：《蛋仔派对》《燕云十六声》

## 三、难度与淘汰率

| 指标 | 数据 |
|------|------|
| 整体难度 | 4/5 星（高于一般互联网中厂，接近头部大厂游戏部门） |
| 总录取率 | 本科生录取率不到 5% |
| 二面淘汰率 | 67%-83%（杭州场 6 进 2 的典型比例） |
| 挂人高频原因 | "基础知识都了解，但没有深刻理解，学习不够透彻" |

### 各轮预计通过率
| 环节 | 预计通过率 | 说明 |
|------|-----------|------|
| 简历筛选 | ~30% | 学历 + 项目双重要 |
| 笔试 | ~50% | 编程题 + 选择题，做出 1/3 也可能约面 |
| 一面 | ~30% | 基础不扎实最易挂 |
| 二面 | ~20% | 图形学/架构薄弱最易挂 |
| HR 面 | ~70% | 文化匹配度、意向确认 |

## 四、面试官风格

### 总体风格
- **友好专业型**：多数面试官"很 nice"、"会给提示"、"不会刻意刁难"
- **追问深挖型**：遇到感兴趣的点会持续追问，直到触及候选人知识边界
- **引导型**：卡住时会适当引导思路，关注推理过程而非死记硬背的答案

### 各轮面试官特点
| 轮次 | 面试官角色 | 风格特点 |
|------|-----------|---------|
| 一面 | 组内资深工程师 | 友善、会给提示、重基础广度 |
| 二面 | 高级工程师/技术主管 | 追问深、压力较大、重深度和架构 |
| 三面/总监面 | 项目组大佬/总监 | 系统性提问、重底层原理和思维方式 |
| HR 面 | HRBP | 友善但有压力、关注真诚度和文化匹配 |

### 候选人反馈
- "面试官很友善，会引导思路"
- "二面面试官现场教了很多东西"
- "二面压力较大，每个问题都被疯狂追问"
- "HR 小姐姐人很好"

## 六、准备建议

### 知识准备优先级
1. **C++/Csharp 基础**（第一优先级）：虚函数、内存管理、智能指针、GC、STL 容器底层实现必须深入理解
2. **算法手撕**：LeetCode Hot100 + 剑指Offer，中等难度为主；快排/DP/二分/链表/栈为最高频
3. **图形学**：渲染管线、Early-Z、延迟渲染、Blinn-Phong、SSAO、阴影技术 必准备
4. **Unity 引擎**：生命周期、协程、AssetBundle、对象池、DrawCall 优化、UGUI
5. **网络同步**：帧同步 vs 状态同步（雷火必考，互娱也高频）
6. **Lua**（雷火重点）：元表、闭包、热更新原理、Csharp 交互

### 项目准备
- 每个项目都能讲清：为什么做、技术选型原因、最大难点及解决方案、优化效果量化
- 最好有自己主导的完整 Unity 游戏 Demo 或编辑器工具
- GitHub 代码规范、README 清晰

### 游戏理解
- 深度体验至少 1 款网易游戏，能写技术分析报告（渲染、优化、Gameplay 架构）
- 准备"喜欢什么游戏"的深度回答（技术 + 设计层面）

### 准备周期
- **4-8 周**全职准备，重点补齐语言基础 + 算法手撕 + Unity 引擎原理
- 面试前 1 周集中刷面经、查漏补缺
