## 🎯 一句话结论（自测用）
> 二叉树路径和：DFS 维护当前路径和，叶节点时对比 target 或累加结果。前序+中序重建：前序首元素为根，中序中找根位置，递归构建左右子树。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **根到叶数字拼接求和（LeetCode 129）**：DFS，`cur = cur*10 + node.val`，叶节点时加到结果
2. **路径和是否存在（LeetCode 112）**：DFS，每层 `target -= node.val`，叶节点时判断 target==0
3. **前序+中序重建二叉树（LeetCode 105）**：前序首元素是根，中序中找根位置分左右，递归
4. **N叉树最大和（LeetCode 337）**：树形 DP，每个节点记录 [不取, 取] 两种状态的最大值

## 🔍 详细解析

### 1. 根到叶数字拼接求和（LeetCode 129）
```cpp
int sumNumbers(TreeNode* root) {
    int total = 0;
    dfs(root, 0, total);
    return total;
}

void dfs(TreeNode* node, int cur, int& total) {
    if (!node) return;
    cur = cur * 10 + node->val;
    if (!node->left && !node->right) {  // 叶节点
        total += cur;
        return;
    }
    dfs(node->left, cur, total);
    dfs(node->right, cur, total);
}
```

### 2. 路径和（LeetCode 112）
```cpp
bool hasPathSum(TreeNode* root, int targetSum) {
    if (!root) return false;
    if (!root->left && !root->right)
        return root->val == targetSum;
    return hasPathSum(root->left, targetSum - root->val) ||
           hasPathSum(root->right, targetSum - root->val);
}
```

### 3. 前序+中序重建二叉树（LeetCode 105）
```cpp
class Solution {
    unordered_map<int, int> inMap;  // 值 -> 中序索引，加速查找
    
    TreeNode* build(vector<int>& pre, int ps, int pe,
                    vector<int>& in, int is, int ie) {
        if (ps > pe) return nullptr;
        
        int rootVal = pre[ps];
        TreeNode* root = new TreeNode(rootVal);
        int rootIdx = inMap[rootVal];
        int leftLen = rootIdx - is;
        
        root->left = build(pre, ps+1, ps+leftLen, in, is, rootIdx-1);
        root->right = build(pre, ps+leftLen+1, pe, in, rootIdx+1, ie);
        return root;
    }
    
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        for (int i = 0; i < inorder.size(); i++)
            inMap[inorder[i]] = i;
        return build(preorder, 0, preorder.size()-1,
                     inorder, 0, inorder.size()-1);
    }
};
```

### 4. N叉树最大和 / 打家劫舍 III（LeetCode 337）
```cpp
// 返回 pair<不取当前节点最大值, 取当前节点最大值>
pair<int,int> dfs(TreeNode* root) {
    if (!root) return {0, 0};
    auto left = dfs(root->left);
    auto right = dfs(root->right);
    
    int notTake = max(left.first, left.second) + max(right.first, right.second);
    int take = root->val + left.first + right.first;
    // 注意：取当前节点时，子节点必须不取，所以用 left.first（不取左子）和 right.first（不取右子）
    return {notTake, take};
}

int rob(TreeNode* root) {
    auto res = dfs(root);
    return max(res.first, res.second);
}
```

### 二叉树遍历模板速查
```cpp
// 前序（根左右）-- 用于序列化
void preorder(TreeNode* root) {
    if (!root) return;
    visit(root);
    preorder(root->left);
    preorder(root->right);
}

// 中序（左根右）-- BST 中为有序序列
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);
    visit(root);
    inorder(root->right);
}

// 后序（左右根）-- 删除节点/计算高度
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    visit(root);
}

// 层次（BFS）-- 最短路径/逐层处理
void levelorder(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        TreeNode* node = q.front(); q.pop();
        visit(node);
        if (node->left) q.push(node->left);
        if (node->right) q.push(node->right);
    }
}
```

## 💬 面试官常见追问
- "怎么判断一棵树是 BST？" -> 中序遍历结果递增，或递归检查范围 `(min, max)`
- "只用前序+后序能重建吗？" -> 不能唯一确定（除非树是真二叉树/完全二叉树）
- "路径和需要返回所有路径（不只有没有）怎么做？" -> DFS 回溯，维护 currentPath，叶节点时拷贝一份

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：路径和问题中，非根到叶的路径也算。题目通常要求"从根到叶"，注意审题
- **误区**：重建二叉树时忘了用哈希表存储中序索引。每次遍历中序数组找根是 O(n^2)，用 map 可以 O(n)
- **误区**：打家劫舍 III 的取和不取逻辑混淆。取当前节点 -> 子节点必须不取（用 first），不取当前 -> 子节点可取可不取（用 max）
