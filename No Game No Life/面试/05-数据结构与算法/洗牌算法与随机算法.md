## 🎯 一句话结论（自测用）
> Fisher-Yates 洗牌：从后往前，每次从 [0, i] 中随机选一个和 i 交换。时间复杂度 O(n)，能生成 n! 种等概率排列。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **Fisher-Yates 洗牌算法**：从最后一个元素开始，每次随机选取 [0, i] 范围内的元素与位置 i 交换。保证 n! 种排列等概率
2. **均匀性证明**：每个元素出现在每个位置的概率都是 1/n
3. **常见错误**：每次从 [0, n-1] 全范围随机选两个交换 -> 不是均匀分布（n^n 种结果无法均匀映射到 n! 种排列）
4. **游戏开发应用**：牌堆洗牌、随机生成地图、Loot 掉落池
5. **加权随机**：累积概率法，`cumulative[i] += weight[i]`，然后 `Random.value * total_weight` 二分查找

## 🔍 详细解析

### Fisher-Yates 洗牌（Knuth 版本）
```cpp
void shuffle(vector<int>& nums) {
    int n = nums.size();
    for (int i = n - 1; i > 0; i--) {
        int j = rand() % (i + 1);  // [0, i]
        swap(nums[i], nums[j]);
    }
}
```
时间复杂度 O(n)，空间 O(1)。从前往后也可以：`swap(nums[i], nums[i + rand()%(n-i)])`。

### 常见错误做法（不均匀）
```cpp
// 错误！不是均匀分布
for (int i = 0; i < n; i++) {
    int j = rand() % n;  // 从 [0, n-1] 全范围选
    swap(nums[i], nums[j]);
}
// 问题：n^n 种可能无法被 n! 整除，导致不均匀
```

### 游戏中的加权随机
```cpp
int weightedRandom(vector<int>& weights) {
    vector<int> prefix(weights.size());
    prefix[0] = weights[0];
    for (int i = 1; i < weights.size(); i++)
        prefix[i] = prefix[i-1] + weights[i];
    int total = prefix.back();
    int r = rand() % total;
    // 二分查找第一个 > r 的索引
    return upper_bound(prefix.begin(), prefix.end(), r) - prefix.begin();
}
```

### 圆形区域均匀随机取点
面试题：吃鸡空投圈内随机取点。
```cpp
// 先按面积比例随机半径，再随机角度
float r = sqrt(Random.Range(0f, 1f)) * maxRadius;
float angle = Random.Range(0f, 2f * Mathf.PI);
float x = centerX + r * cos(angle);
float y = centerY + r * sin(angle);
```
关键：半径要用平方根（因为面积与 r^2 成正比），否则中心区域概率过高。

## 💬 面试官常见追问
- "如何证明 Fisher-Yates 是均匀的？" -> 数学归纳法：最后一个位置每个元素概率 1/n，倒数第二个每个剩余元素概率 1/(n-1)，连乘得 1/n!
- "如何生成指定概率分布的随机？" -> 累积概率法（轮盘赌）
- "C++ `rand()` 有什么问题？" -> 范围有限（RAND_MAX 通常 32767），周期短，非线程安全。推荐 `<random>` 库的 `mt19937`

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：洗牌用全范围随机交换。不均匀，这是面试官想考察的核心陷阱
- **误区**：圆形随机取点用 `r = random * maxRadius`。中心区域概率过高，因为小半径的圆面积小
