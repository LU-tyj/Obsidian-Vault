## 🎯 一句话结论（自测用）
> HR 面淘汰率约 30%，主要考察文化匹配度、职业规划、对网易/游戏的热爱和理解。核心考察点：是否真心想做游戏（而非拿游戏当跳板）、是否了解网易、是否有清晰的职业规划。反问要展现对技术成长和业务的关心，避免只问薪资福利。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）

### 一、HR 面高频问题（出现频次排序）

#### ⭐⭐⭐ 极高频（几乎每场必问）
| 问题 | 回答策略 |
|------|---------|
| **为什么想做游戏？（而不是其他软件行业）** | 展现热情和长期规划：从小玩什么游戏 -> 某个游戏触动到你 -> 想做让人快乐的游戏 -> 技术手段实现 |
| **手上有其他 offer 吗？给了 offer 有多大把握会来？** | 诚实但不卑微：有 offer 正常，但更看好网易的游戏基因和项目质量（具体项目名称） |
| **对工作地点的意愿（上海/广州/杭州）？** | 表现灵活，说明理由（如杭州离家近/广州游戏氛围好），但要有首选 |
| **对未来职业的规划？** | 短期（1-2 年）：熟悉业务、积累项目经验；中期（3-5 年）：成为某方向专家（渲染/Gameplay）；长期：技术 leader 或架构师 |

#### ⭐⭐ 高频
| 问题 | 回答策略 |
|------|---------|
| **项目中最有成就感的事？** | 具体事件 + 技术难点 + 解决过程 + 量化成果 |
| **平时怎么学习技术？** | 官方文档 + 源码阅读 + 博客/论文 + 实践验证（不要只说"看视频"） |
| **对网易哪个项目/工作室感兴趣？** | 提前了解至少 2 个网易项目，能说出技术亮点和自己的理解 |
| **优缺点？** | 优点：技术相关（如学习能力强、代码规范）；缺点：非致命 + 改进计划（如公开演讲能力不足，正在通过内部分享练习） |
| **团队合作经历与冲突解决？** | STAR 法则：情境-任务-行动-结果 |
| **GameJam 经历？** | 有就详细讲，没有就说对独立开发/Demo 的经历 |
| **对加班的态度？** | 接受合理的加班（版本节点），但不接受无效的内卷；展现结果导向 |

#### ⭐ 中频
| 问题 | 回答策略 |
|------|---------|
| 能否提前实习？ | 如实回答，一般越早越好 |
| 对薪资的期望？ | 提前查好范围，不用急着报具体数字 |
| 其他兴趣爱好？ | 展现多元化：运动/阅读/独立游戏开发等 |

| 岗位类型 | 年薪范围 | 月薪范围 | 薪资结构 |

| 实习（日薪） | 约 300-500/天 | - | 按月结算 |

### 三、反问环节（展现关注点）

#### ✅ 好的反问
| 问题 | 为什么好 |
|------|---------|
| "我加入后主要负责哪个项目/模块？" | 展现对业务的好奇心 |
| "团队的技术栈和目前的技术挑战是什么？" | 展现技术追求 |
| "新人入职后的培养计划/导师制度是怎样的？" | 展现成长意愿 |
| "团队目前的人员规模和分工？" | 了解团队结构 |
| "项目目前处于什么阶段？（预研/开发中/上线后）" | 了解项目现状 |

#### ❌ 避免的反问
- "加班多吗？" -> 可以问，但不要作为第一个问题
- "薪资能再谈吗？" -> HR 面不适合谈，留给 offer 阶段
- 只问福利（食堂/健身房/班车）不问业务 -> 显得对工作本身不关心
- "我面试表现怎么样？" -> HR 不一定知道技术面评价

---

### 四、HR 面注意事项

1. **不要冷场**：每个问题准备 2-3 句话的回答框架
2. **不要背诵感太强**：自然回应，展现真诚
3. **对网易的了解**：至少提前玩过 1 款网易游戏，能说出技术层面的分析
4. **文化匹配**：网易注重"热爱游戏"和"技术追求"，要自然展现
5. **态度**：自信但不傲慢，诚实但不卑微

---

### 五、流程中的特殊情况

- **无 HR 面直接 OC**：部分批次（如实习生补录）可能跳过 HR 面，直接发邮件录用函
- **HR 面后 OC 时间**：通常 3-5 个工作日，最长 1 周
- **HR 面也刷人**：如果表现出对游戏行业无热情、职业规划不清晰、沟通能力差，可能挂
