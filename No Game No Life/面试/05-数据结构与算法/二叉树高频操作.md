## 🎯 一句话结论（自测用）
> 二叉树面试核心：DFS递归三件套（前中后序）、LCA（左右子树递归）、路径和（DFS回溯 + 前缀和）、N叉树相邻不可取（树形DP）。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **遍历**：前序（根左右）、中序（左根右，BST 有序）、后序（左右根，用于删除）、层次遍历（BFS 队列）
2. **LCA（最近公共祖先）**：递归，root 等于 p/q 则返回；左右子树递归结果都不为空则 root 是 LCA
3. **路径和（根到叶数字拼接）**：DFS 传当前值 `cur = cur*10 + node.val`，叶节点时累加到结果
4. **前序+中序重建二叉树**：前序首元素为根，中序中找根位置，递归构建左右子树
5. **N叉树结点值最大和（不能同时取相邻）**：树形DP，`dp[node][0]`=不取当前节点，`dp[node][1]`=取当前节点。`rob = max(take, notTake)`

## 🔍 详细解析

### 二叉树遍历框架
```
// 前序
void preorder(root) { if(!root) return; visit(root); preorder(root.left); preorder(root.right); }

// 中序（BST中为有序序列）
void inorder(root) { if(!root) return; inorder(root.left); visit(root); inorder(root.right); }

// 后序
void postorder(root) { if(!root) return; postorder(root.left); postorder(root.right); visit(root); }

// 层次
void levelorder(root) {
    queue<TreeNode*> q; q.push(root);
    while(!q.empty()) { auto n = q.front(); q.pop(); visit(n); if(n.left) q.push(n.left); if(n.right) q.push(n.right); }
}
```

### LCA 详解
```cpp
TreeNode* LCA(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    TreeNode* left = LCA(root->left, p, q);
    TreeNode* right = LCA(root->right, p, q);
    if (left && right) return root;  // p和q分别在左右子树
    return left ? left : right;       // 在一边，或都不在
}
```
时间复杂度 O(n)，空间 O(h)。BST 版本可利用 BST 性质 O(logn) 解决。

### 路径和（LeetCode 129）
根到叶节点数字拼接求和。DFS 时 `cur = cur * 10 + node->val`，到叶节点则加到结果。

### 前序+中序重建二叉树（LeetCode 105）
```cpp
TreeNode* build(vector<int>& pre, vector<int>& in, int ps, int pe, int is, int ie) {
    if (ps > pe) return NULL;
    TreeNode* root = new TreeNode(pre[ps]);
    int pos = find(in.begin()+is, in.begin()+ie+1, pre[ps]) - in.begin();
    int leftLen = pos - is;
    root->left = build(pre, in, ps+1, ps+leftLen, is, pos-1);
    root->right = build(pre, in, ps+leftLen+1, pe, pos+1, ie);
    return root;
}
```

### N叉树最大和（LeetCode 337 House Robber III 变体）
```cpp
pair<int,int> dfs(TreeNode* root) {  // first=不取, second=取
    if (!root) return {0, 0};
    auto l = dfs(root->left);
    auto r = dfs(root->right);
    int notTake = max(l.first, l.second) + max(r.first, r.second);
    int take = root->val + l.first + r.first;
    return {notTake, take};
}
```

## 💬 面试官常见追问
- "BFS 和 DFS 用什么数据结构？" -> BFS 用队列，DFS 用栈（或递归）
- "如何判断二叉树是否对称？" -> 递归比较 `left.left vs right.right` 和 `left.right vs right.left`
- "二叉树的直径怎么求？" -> 后序遍历，每个节点计算左右深度和，更新全局最大值

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：中序+后序也能重建，但前序+后序不能唯一确定（除非是真二叉树）
- **误区**：LCA 忘记处理 p 是 q 的祖先的情况。递归写法天然处理了
