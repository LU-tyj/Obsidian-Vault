## 🎯 一句话结论（自测用）
> 二分查找核心：有序数组 + 左右指针收缩。模板：`while(l<=r)` 配合 `mid=l+(r-l)/2` 防溢出。关键变形：找第一个 >= target / 找最后一个 <= target。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **基本二分**：有序数组，每次取中间元素比较，一半一半缩小范围。O(log n)
2. **标准模板**：
   - `while (l <= r)`：搜索区间 [l, r]，找到 target 返回 mid，否则根据大小调整 l 或 r
   - `mid = l + (r - l) / 2`：防溢出（不用 `(l+r)/2`）
3. **常见变形**：
   - 找第一个 >= target（lower_bound）：`while(l<r)`，`mid=(l+r)/2`，`nums[mid]>=target` 时 `r=mid` 否则 `l=mid+1`
   - 找最后一个 <= target（upper_bound - 1）
4. **面试变体/场景题**：
   - 有序数组中找大于某个数的第一个元素（带偏向二分）
   - 查找 IP 属于哪个 IP 段：IP 段有序，二分找覆盖区间
   - 旋转有序数组找最小值：二分判断哪边有序

## 🔍 详细解析

### 标准二分模板
```cpp
int binarySearch(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) l = mid + 1;
        else r = mid - 1;
    }
    return -1;
}
```

### 找第一个 >= target（lower_bound）模板
```cpp
int lowerBound(vector<int>& nums, int target) {
    int l = 0, r = nums.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] >= target) r = mid;
        else l = mid + 1;
    }
    return l;  // l == r, 第一个 >= target 的位置
}
```

### 面试场景题：查找 IP 属于哪个 IP 段
- IP 地址转换为 32 位整数
- IP 段按起始地址排序，使用二分查找
- 无交集时直接二分，有交集时需要检查最右覆盖
- 进阶：IP 数量极大时可用 Trie 树优化

### 旋转有序数组找最小值（LeetCode 153）
```cpp
int findMin(vector<int>& nums) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] > nums[r]) l = mid + 1;  // 最小值在右边
        else r = mid;                           // 最小值在左边或就是 mid
    }
    return nums[l];
}
```

## 💬 面试官常见追问
- "为什么用 `mid = l + (r-l)/2` 而不是 `(l+r)/2`？" -> 防整数溢出。当 l 和 r 都很大时 l+r 可能溢出
- "二分查找有哪些变形？" -> lower_bound（第一个>=）、upper_bound（第一个>）、找第一个和最后一个位置 (LeetCode 34)
- "如果数组有重复元素怎么处理？" -> 用 lower_bound 找第一个，upper_bound 找最后一个

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：while 条件写成 `l < r`（左边闭右边开），但搜索范围处理不一致导致死循环
- **误区**：`mid = (l+r)/2`。大数组会溢出
- **误区**：二分只适用于有序数组。可以用在"单调函数"的取值上，比如平方根、判断某条件是否满足
