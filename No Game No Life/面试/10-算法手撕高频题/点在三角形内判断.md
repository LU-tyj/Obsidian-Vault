## 🎯 一句话结论（自测用）
> 重心坐标法（Barycentric）：计算 P 相对于三角形三个顶点的重心坐标 u,v,w，若 u>=0 && v>=0 && w>=0 且 u+v+w=1 则点在内。或用叉积法：P 在三条边的同一侧。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **叉积法（Cross Product，推荐）**：P 与三角形每条边做叉积，三次结果同号（同正或同负）则 P 在内
2. **重心坐标法（Barycentric）**：解方程 `P = u*A + v*B + w*C`（u+v+w=1），u,v,w 都在 [0,1] 则在内
3. **面积法**：`Area(PBC)+Area(PCA)+Area(PAB) == Area(ABC)` 则在内

## 🔍 详细解析

### 方法一：叉积法（最常用）
```cpp
struct Point { float x, y; };

// 叉积 = |AB x AP| 的 Z 分量（2D cross product）
float cross(Point a, Point b, Point p) {
    return (b.x - a.x) * (p.y - a.y) - (b.y - a.y) * (p.x - a.x);
}

bool isPointInTriangle(Point p, Point a, Point b, Point c) {
    float c1 = cross(a, b, p);
    float c2 = cross(b, c, p);
    float c3 = cross(c, a, p);
    
    // 同号（都在同一侧）
    bool hasNeg = (c1 < 0) || (c2 < 0) || (c3 < 0);
    bool hasPos = (c1 > 0) || (c2 > 0) || (c3 > 0);
    
    return !(hasNeg && hasPos);  // 如果有正有负，则在外面
}
```

### 方法二：重心坐标法
```cpp
bool isPointInTriangleBarycentric(Point p, Point a, Point b, Point c) {
    float v0x = c.x - a.x, v0y = c.y - a.y;
    float v1x = b.x - a.x, v1y = b.y - a.y;
    float v2x = p.x - a.x, v2y = p.y - a.y;
    
    float dot00 = v0x * v0x + v0y * v0y;
    float dot01 = v0x * v1x + v0y * v1y;
    float dot02 = v0x * v2x + v0y * v2y;
    float dot11 = v1x * v1x + v1y * v1y;
    float dot12 = v1x * v2x + v1y * v2y;
    
    float invDenom = 1.0f / (dot00 * dot11 - dot01 * dot01);
    float u = (dot11 * dot02 - dot01 * dot12) * invDenom;
    float v = (dot00 * dot12 - dot01 * dot02) * invDenom;
    
    return (u >= 0) && (v >= 0) && (u + v <= 1);
}
```

    bool hasPos = c1 > 0 || c2 > 0 || c3 > 0;

}

### 3D 场景：点是否在三角形内（面经 005_Q26）
在 3D 空间中，通过投影到 2D 平面来判断：
```cpp
bool isPointInTriangle3D(Vector3 p, Vector3 a, Vector3 b, Vector3 c) {
    // 计算三角形法线
    Vector3 normal = Cross(b - a, c - a);
    // 选择法线的两个最大分量所在平面做投影（避免退化）
    if (abs(normal.x) >= abs(normal.y) && abs(normal.x) >= abs(normal.z))
        // 投影到 YZ 平面
        return isPointInTriangle2D({p.y, p.z}, {a.y, a.z}, {b.y, b.z}, {c.y, c.z});
    else if (abs(normal.y) >= abs(normal.z))
        // 投影到 XZ 平面
        return isPointInTriangle2D({p.x, p.z}, {a.x, a.z}, {b.x, b.z}, {c.x, c.z});
    else
        // 投影到 XY 平面
        return isPointInTriangle2D({p.x, p.y}, {a.x, a.y}, {b.x, b.y}, {c.x, c.y});
}
```

### 三种方法对比
| 方法 | 复杂度 | 适用 | 说明 |
|------|--------|------|------|
| 叉积法 | O(1) | 2D/3D | 最直观，注意方向一致性问题 |
| 重心坐标法 | O(1) | 2D | 还可计算 u,v 用于插值（光照、纹理） |
| 面积法 | O(1) | 2D | 直观但浮点精度问题（面积比较用容差） |

## 💬 面试官常见追问
- "叉积法三个结果的正负方向怎么定？" -> 取决于三角形顶点的顺序（顺时针 vs 逆时针）。只要三个结果同号即可，不用纠结正负
- "如何判断点是否在三角形边上？" -> 某个叉积结果为 0（但仍需另外两个同号）。可根据需求包含或排除边界
- "重心坐标法除了判断是否在内外还有什么用途？" -> 重心坐标 (u,v,w) 可直接用于顶点属性插值（如 Phong 着色中的法线插值）

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：叉积法认为三个结果必须全正或全负。正确是三个结果不能有正有负（允许 0 表示在边上）
- **误区**：3D 测试时直接在 3D 空间中做叉积。3D 叉积结果是向量，无法直接比较正负，需要投影到 2D
- **误区**：面积法直接用 `==` 比较。浮点数有精度误差，应该用 `|总-分和| < epsilon`
