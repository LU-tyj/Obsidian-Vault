## 🎯 一句话结论（自测用）
> ShadowMap 是最基础的阴影技术，从光源视角渲染深度图再通过深度比较判断是否在阴影中。PCF 和 PCSS 通过采样滤波实现软阴影，CSM 通过多级 ShadowMap 解决大场景远景阴影精度不足的问题。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）

**1. ShadowMap（基础）**：
- Pass 1：以光源为摄像机渲染场景深度图（ShadowMap）
- Pass 2：正常渲染时，将片元变换到光源空间，比较其深度与 ShadowMap 中的深度。深度 > ShadowMap 深度 -> 在阴影中

**2. PCF（Percentage Closer Filtering）**：
- 对 ShadowMap 采样点周围 NxN 区域做多次深度比较，取"被照亮的采样点数 / 总采样数"作为阴影强度
- 效果：阴影边缘有渐变的软阴影效果
- 代价：多次采样增加 GPU 开销

**3. PCSS（Percentage Closer Soft Shadows）**：
- 在 PCF 基础上，根据遮挡物距离自动调整采样半径：遮挡物越近 -> 半径越小 -> 阴影越硬；遮挡物越远 -> 半径越大 -> 阴影越软
- 更符合物理实际（太阳光下的阴影：物体离地面越近阴影边缘越硬）

**4. CSM（Cascaded Shadow Maps）**：
- 将视锥体按距离分割为多个级联层，每层使用不同分辨率的 ShadowMap
- 近处用高分辨率 ShadowMap，远处用低分辨率 ShadowMap
- 解决了单一 ShadowMap 在大场景中近处阴影锯齿、远处精度不足的问题
- Unity 中通过 Quality Settings 配置级联层级数（通常 2-4 级）

## 🔍 详细解析

**ShadowMap 的问题与解决**：

| 问题 | 现象 | 解决方案 |
|------|------|----------|
| 阴影锯齿 | 阴影边缘有阶梯状 | PCF / 提高 ShadowMap 分辨率 |
| 阴影痤疮 | 表面出现错误的自遮挡条纹 | Shadow Bias / Normal Bias |
| 彼得潘现象 | 阴影与物体分离 | 降低 Bias / 使用双面阴影 |
| 近处精度不足 | 近景阴影粗糙 | CSM（级联阴影） |

**Shadow Acne 的本质**：
ShadowMap 的每个像素覆盖一个世界空间区域，当视线方向和光源方向形成的角度较小时，一个 ShadowMap 像素可能覆盖了应该被照亮和被遮挡的两个点，导致自遮挡错误。解决方式是加一个深度偏移（Depth Bias 或 Normal Bias）。

## 💬 面试官常见追问
- "ShadowMap 痤疮（Acne）是怎么产生的？如何解决？" -> 见上表；本质是 ShadowMap 分辨率限制 + 离散采样 + 浮点精度导致的错误自遮挡
- "PCF 和 PCSS 的计算代价差异？" -> PCF 固定采样半径，PCSS 还需要额外的 blocker search pass 来确定遮挡物距离，开销更大
- "CSM 的级联分层策略？" -> 通常近处占 20% 视距但用 50% 的 ShadowMap 面积，远处占 80% 视距用剩余 50%

## ⚠️ 我曾经的误区 / 网上常见错答
- 误区：PCF 就是直接模糊 ShadowMap。实际上 PCF 是对深度比较的结果做滤波，不是对深度值做滤波——如果先模糊深度图再做比较，结果会完全不正确
- 误区：CSM 就是多个 ShadowMap 重叠。CSM 每级覆盖不同的视距范围，各级之间不重叠（或小范围过渡）
