## 🎯 一句话结论（自测用）
> 选基准 -> 分区（小的放左，大的放右）-> 递归排序左右。空间 O(log n)（递归栈），不稳定。优化的三个关键点：随机化基准、三数取中、小数组切换插入排序。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. 选基准（pivot）
2. 分区（partition）：比基准小的放左边，大的放右边，返回基准最终位置
3. 递归调用左右子数组
4. 时间复杂度：平均 O(nlogn)，最坏 O(n^2)（基本有序时）
5. 空间复杂度：O(logn)（递归栈深度）
6. 不稳定排序

## 🔍 详细解析

### 标准快排（C++）
```cpp
// 分区函数：选最后一个元素为基准
int partition(vector<int>& nums, int left, int right) {
    int pivot = nums[right];
    int i = left;  // i 指向第一个 >= pivot 的位置
    for (int j = left; j < right; j++) {
        if (nums[j] < pivot) {
            swap(nums[i], nums[j]);
            i++;
        }
    }
    swap(nums[i], nums[right]);  // 基准放到正确位置
    return i;
}

void quickSort(vector<int>& nums, int left, int right) {
    if (left >= right) return;
    int pivotIndex = partition(nums, left, right);
    quickSort(nums, left, pivotIndex - 1);
    quickSort(nums, pivotIndex + 1, right);
}
```

### 优化版快排（随机化基准 + 三数取中）
```cpp
// 三数取中，避免基本有序退化
int medianOfThree(vector<int>& nums, int left, int right) {
    int mid = left + (right - left) / 2;
    if (nums[left] > nums[mid]) swap(nums[left], nums[mid]);
    if (nums[left] > nums[right]) swap(nums[left], nums[right]);
    if (nums[mid] > nums[right]) swap(nums[mid], nums[right]);
    swap(nums[mid], nums[right]);  // 将中位数放到 right 作为基准
    return nums[right];
}

int partitionOptimized(vector<int>& nums, int left, int right) {
    int pivot = medianOfThree(nums, left, right);
    int i = left;
    for (int j = left; j < right; j++) {
        if (nums[j] < pivot) {
            swap(nums[i], nums[j]);
            i++;
        }
    }
    swap(nums[i], nums[right]);
    return i;
}

// 优化版：小数组时切换插入排序
void quickSortOptimized(vector<int>& nums, int left, int right) {
    if (right - left <= 10) {
        insertionSort(nums, left, right);  // 小数组用插入排序
        return;
    }
    if (left >= right) return;
    int pivotIndex = partitionOptimized(nums, left, right);
    quickSortOptimized(nums, left, pivotIndex - 1);
    quickSortOptimized(nums, pivotIndex + 1, right);
}
```

### Csharp 版本
```csharp
public static class QuickSort
{
    public static void Sort(int[] arr, int left, int right)
    {
        if (left >= right) return;
        int pivotIndex = Partition(arr, left, right);
        Sort(arr, left, pivotIndex - 1);
        Sort(arr, pivotIndex + 1, right);
    }

    private static int Partition(int[] arr, int left, int right)
    {
        int pivot = arr[right];
        int i = left;
        for (int j = left; j < right; j++)
        {
            if (arr[j] < pivot)
            {
                (arr[i], arr[j]) = (arr[j], arr[i]);
                i++;
            }
        }
        (arr[i], arr[right]) = (arr[right], arr[i]);
        return i;
    }
}
```

### 非递归版快排（用栈模拟递归，避免栈溢出）
```cpp
void quickSortIterative(vector<int>& nums) {
    stack<pair<int,int>> st;
    st.push({0, (int)nums.size()-1});
    while (!st.empty()) {
        auto [left, right] = st.top(); st.pop();
        if (left >= right) continue;
        int pivot = partition(nums, left, right);
        st.push({left, pivot-1});
        st.push({pivot+1, right});
    }
}
```

## 💬 面试官常见追问
- "快排空间复杂度是多少？" -> O(log n)，递归栈深度
- "为什么要随机化基准？" -> 防止基本有序数组退化到 O(n^2)
- "为什么实际中快排比堆排快？" -> 快排缓存友好（连续内存访问）、常数因子小
- "三路快排了解吗？" -> 处理大量重复元素时用，分成 < pivot | == pivot | > pivot 三部分

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：快排空间 O(1)。错，递归栈 O(log n)
- **误区**：partition 中的 i 初始位置。应该初始化为 left（指向第一个 >= pivot 的位置），不是 left+1
- **误区**：递归时忘了 `pivotIndex-1` 和 `pivotIndex+1`，写成 `quickSort(nums, left, pivotIndex)` 导致无限递归
