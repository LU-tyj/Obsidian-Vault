## 🎯 一句话结论（自测用）
> 位运算三件套：`n & (n-1)` 消除最低位 1（判断 2 的幂/统计 1 的个数），`n & 1` 判奇偶，`n ^ n = 0` 找只出现一次的数。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **判断 2 的 n 次方**：`n > 0 && (n & (n-1)) == 0`。因为 2^n 的二进制只有一位是 1
2. **统计二进制中 1 的个数（Brian Kernighan）**：每次 `n &= (n-1)` 消去最低位的 1，计数+1。O(k)，k 为 1 的个数
3. **判断奇偶**：`(n & 1) == 0` 偶数，`== 1` 奇数。比 `n % 2` 更高效
4. **交换两个数（不用临时变量）**：`a ^= b; b ^= a; a ^= b;`
5. **只出现一次的数（其余出现两次）**：所有数异或，结果就是那个数。`x ^ x = 0, x ^ 0 = x`

## 🔍 详细解析

### 判断 2 的 n 次方
```cpp
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
// 原理：2^n 如 1000B，n-1 如 0111B，相与为 0
```

### 统计 1 的个数
```cpp
int countOnes(int n) {
    int count = 0;
    while (n) {
        n &= (n - 1);  // 消除最低位的 1
        count++;
    }
    return count;
}
```

### 交换两个数（异或法）
```cpp
void swap(int& a, int& b) {
    a ^= b;
    b ^= a;  // b = b ^ a ^ b = a
    a ^= b;  // a = a ^ b ^ a = b
}
// 注意：a 和 b 不能是同一变量（否则会变为 0）
```

### 常见位运算操作速查表
| 操作 | 表达式 |
|------|--------|
| 获取最低位 1 | `n & -n` |
| 消除最低位 1 | `n & (n-1)` |
| 判断奇偶 | `n & 1` |
| 乘 2 | `n << 1` |
| 除 2 | `n >> 1` |
| 取第 k 位 | `(n >> k) & 1` |
| 设第 k 位为 1 | `n \| (1 << k)` |
| 设第 k 位为 0 | `n & ~(1 << k)` |

## 💬 面试官常见追问
- "位运算在游戏开发中有什么应用？" -> Layer Mask（`1 << layer`）、权限位标记、高效状态存储、网络协议中的位压缩
- "为什么 `(n & 1)` 比 `n % 2` 快？" -> 位运算直接在 CPU 位运算单元完成，取模需要除法运算（更慢）

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：判断 2 的 n 次方忘了 `n > 0`。`n=0` 时 `(0 & -1) == 0` 也成立，但不是 2 的幂
- **误区**：异或交换 `a^=b; b^=a; a^=b;` 只适用于整数类型，浮点数不能用异或交换
