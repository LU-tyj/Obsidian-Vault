### Q2: Unity 组件模式

- Unity 的组件模式是什么？
- 常用组件有哪些？（Transform、Collider、Rigidbody、Mesh、Animator 等）

### Q3: 预制体（Prefab）

- 预制体的概念和作用是什么？
- 使用场景有哪些？

### Q4: Unity 生命周期

- 完整描述 Unity 生命周期顺序
- Awake -> OnEnable -> Start -> Update -> LateUpdate -> FixedUpdate -> OnDisable -> OnDestroy
- 各阶段的适用场景

### Q5: C# Interface vs Abstract Class

- 语法差异：
  - 字段声明：接口不能声明字段，抽象类可以
  - 多继承：接口可以多继承，抽象类只能单继承
- 用法差异：
  - 接口用于定义协议/契约
  - 抽象类用于收纳公共数据逻辑，提供默认实现

### Q6: C# 字符串的不可变性

- 字符串的缺点是什么？
  - 不可变性导致每次修改都要在堆上重新分配内存
  - 相同内容的字符串指向同一地址（字符串驻留/string interning）
- 高频修改字符串的解决方案？
  - 使用 `StringBuilder`，其本质是字符数组，支持原地修改，避免频繁内存分配

### Q7: 算法题 -- 最短路径

- 题目：N x M 网格，0 表示空地，1 表示障碍物，可以上下左右走
- 求从 (0,0) 到 (N-1, M-1) 的最短路径，若无路径则返回 -1
- 解法：BFS 或 DFS，BFS 天然保证最短路径
