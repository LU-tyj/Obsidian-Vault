## 🎯 一句话结论（自测用）
> 排序算法必问快排的时间/空间复杂度和退化情况；TopK用小顶堆（O(nlogk)）；基本有序时插入排序最优。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **十大排序复杂度速查**：冒泡/选择/插入 O(n^2)，希尔 O(nlogn)，归并/快速/堆 O(nlogn)，计数/桶/基数 O(n+k)
2. **不稳定排序**：选择、快速、堆、希尔（口诀："选快堆希"）
3. **基本有序选插入排序**：快速排序在基本有序时退化为 O(n^2)
4. **快速排序核心**：选基准 -> 分区 -> 递归。空间复杂度 O(log n)（递归栈），最坏 O(n^2)
5. **归并排序核心**：分治 + 合并两个有序数组，稳定，空间 O(n)
6. **堆排序核心**：建堆 O(n) + 反复取堆顶调整 O(nlogn)，不稳定，空间 O(1)

## 🔍 详细解析

### 各排序核心思想
| 排序算法 | 核心思想 | 时间复杂度 | 空间复杂度 | 稳定性 |
|---------|---------|-----------|-----------|--------|
| 冒泡 | 相邻比较交换，每轮"冒"最大 | O(n^2) | O(1) | 稳定 |
| 选择 | 每轮选最小放已排序末尾 | O(n^2) | O(1) | 不稳定 |
| 插入 | 未排序元素插入已排序序列 | O(n^2) | O(1) | 稳定 |
| 希尔 | 分组插入排序，逐步缩小间隔 | O(nlogn)~O(n^2) | O(1) | 不稳定 |
| 快速 | 基准分区，递归排序左右 | O(nlogn) | O(logn) | 不稳定 |
| 堆 | 完全二叉树堆结构，取堆顶 | O(nlogn) | O(1) | 不稳定 |
| 归并 | 分治，合并已排序子序列 | O(nlogn) | O(n) | 稳定 |
| 计数 | 统计元素出现次数 | O(n+k) | O(k) | 稳定 |

### 快速排序退化分析
- **退化条件**：每次选到最小/最大元素作为基准（如基本有序数组）
- **解决方案**：随机化选基准 / 三数取中法
- **面试追问**：为什么要随机化？防止构造恶意输入导致 O(n^2)

### 100 万数据选前 1 万大（TopK 变体）
- 小顶堆，先拿前 1 万个建堆
- 遍历剩余元素，若大于堆顶则替换并调整
- O(n log m)，其中 m=10000

## 💬 面试官常见追问
- "快排空间复杂度是多少？" -> O(log n)，不是 O(1)！递归栈深度
- "什么时候用归并不用快排？" -> 要求稳定性、外部排序、链表排序
- "堆排序为什么在实践中不如快排？" -> 缓存不友好（非连续访问）、交换次数多
- "红黑树和AVL树区别？" -> AVL 严格平衡（查询快），红黑树旋转少（插入删除快），STL map 用红黑树

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：快排空间复杂度是 O(1)。实际是 O(log n)，因为有递归栈
- **误区**：堆排序稳定。实际不稳定，建堆过程破坏顺序
- **误区**：希尔排序复杂度永远是 O(n^1.3)。实际取决于增量序列，最坏 O(n^2)
