## 一句话结论（自测用）
> 重载（Overload）：同一作用域，函数名相同、参数不同（类型/个数/顺序），编译期决定调用哪个。重写（Override）：派生类覆盖基类 virtual 函数，签名必须完全一致，运行期用虚表动态绑定。隐藏（Hide）：派生类定义了与基类同名函数（即使签名不同），会把基类的所有同名版本都隐藏。

## 标准答案（结构化、可背诵，2分钟内讲完）
1. **重载（Overload）**：
   - 发生在**同一作用域**（同一个类或同一个命名空间）
   - 函数名相同，参数列表不同（类型、个数、顺序）
   - 返回类型不同不能构成重载
   - 是**编译期多态**
2. **重写（Override）**：
   - 发生在**基类与派生类之间**
   - 派生类函数与基类 virtual 函数**签名完全一致**
   - 基类函数必须有 virtual 关键字
   - 是**运行期多态**，通过虚表动态绑定
   - C++11 加 `override` 关键字，编译器会检查是否真正重写了基类虚函数（推荐使用）
3. **隐藏（Hide）**：
   - 派生类定义了与基类**同名**的函数（即使参数不同）
   - 会使基类中**所有同名函数**在派生类中不可见
   - 需要用 `using Base::func;` 将基类的同名函数引入派生类作用域来消除隐藏

## 详细解析

### 隐藏 vs 重写的判断
```cpp
class Base {
public:
    virtual void func(int x) { }
    void func(double x) { }  // 重载了 func(int)
};

class Derived : public Base {
public:
    void func(int x) override { }  // 重写了 Base::func(int)
    // 没有 using Base::func; → Base::func(double) 被隐藏！
};
```

要点：只要派生类定义了同名函数，基类所有同名函数（不论参数是否一致）默认都被隐藏。

### 重载决议的优先级
1. 完全相同匹配 > 提升转换（float→double）> 标准转换（int→float）> 用户定义转换 > 省略号
2. 模板候选和普通候选并存时，若同等匹配则优先选普通函数

## 面试官常见追问
- 为什么返回类型不能作为重载的条件？（调用时可能忽略返回值：`func();` 编译器无法判断调用哪个版本）
- override 和 final 的区别？（override：声明重写基类虚函数，编译器检查；final：禁止派生类继续重写该函数或禁止继承该类）
- 为什么推荐写 override？（防止拼写错误或参数不匹配导致"想重写但写了新函数"的 bug）
- 构造函数可以重载吗？析构函数呢？（构造可以重载；析构不可以，无参数无返回值）

## 我曾经的误区 / 网上常见错答
- **错**："参数默认值不同可以构成重载" —— 默认值不参与函数签名，默认值不同不能重载，会造成二义性
- **错**："隐藏就是私有继承" —— 机制完全不同：隐藏是名称遮蔽；私有继承是访问控制
- **错**："加了 virtual 就一定触发多态" —— 通过对象（非指针/引用）调用虚函数不触发多态（静态绑定）
