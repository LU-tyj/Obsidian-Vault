## 🎯 一句话结论（自测用）
> 最长公共子串：`dp[i][j] = (s1[i]==s2[j]) ? dp[i-1][j-1]+1 : 0`，记录最大值。最长回文子串：中心扩展法 O(n^2) 或 Manacher O(n)。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **最长公共子串（连续）**：二维 DP，相等时从左上角 +1，不等时清零，过程中记录最大值
2. **最长公共子序列（不连续）**：`dp[i][j] = (s1[i]==s2[j]) ? dp[i-1][j-1]+1 : max(dp[i-1][j], dp[i][j-1])`
3. **最长回文子串**：中心扩展法 -- 遍历每个位置，向两边扩展到最长回文。分奇偶两种情况

## 🔍 详细解析

### 最长公共子串（Longest Common Substring）
```cpp
int longestCommonSubstring(string s1, string s2) {
    int m = s1.size(), n = s2.size(), maxLen = 0;
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i - 1] == s2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
                maxLen = max(maxLen, dp[i][j]);
            }
            // 注意：不等时自然为 0（子串要求连续）
        }
    }
    return maxLen;
}
```
空间优化：只需一维数组 O(n)，保存左上角值。

### 最长公共子序列（Longest Common Subsequence）
```cpp
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1[i - 1] == text2[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m][n];
}
```
**关键区别**：子串不等时清零 `= 0`，子序列不等时取 `max(上, 左)`。

### 最长回文子串（中心扩展法）
```cpp
string longestPalindrome(string s) {
    int start = 0, maxLen = 0;
    int n = s.size();
    
    for (int i = 0; i < n; i++) {
        // 奇数长度回文（一个中心）
        int l = i, r = i;
        while (l >= 0 && r < n && s[l] == s[r]) {
            if (r - l + 1 > maxLen) {
                start = l;
                maxLen = r - l + 1;
            }
            l--; r++;
        }
        
        // 偶数长度回文（两个中心）
        l = i; r = i + 1;
        while (l >= 0 && r < n && s[l] == s[r]) {
            if (r - l + 1 > maxLen) {
                start = l;
                maxLen = r - l + 1;
            }
            l--; r++;
        }
    }
    return s.substr(start, maxLen);
}
```
还可以用 DP：`dp[i][j] = (s[i]==s[j] && (j-i<2 || dp[i+1][j-1]))`

### Csharp 版本
```csharp
// 最长公共子串
public int LongestCommonSubstring(string s1, string s2)
{
    int m = s1.Length, n = s2.Length, maxLen = 0;
    int[,] dp = new int[m + 1, n + 1];  // 默认 0
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (s1[i - 1] == s2[j - 1])
            {
                dp[i, j] = dp[i - 1, j - 1] + 1;
                maxLen = Math.Max(maxLen, dp[i, j]);
            }
    return maxLen;
}

// 最长回文子串
public string LongestPalindrome(string s)
{
    int start = 0, maxLen = 0;
    for (int i = 0; i < s.Length; i++)
    {
        Expand(i, i);     // 奇数
        Expand(i, i + 1); // 偶数
    }
    return s.Substring(start, maxLen);

    void Expand(int l, int r) {
        while (l >= 0 && r < s.Length && s[l] == s[r])
        {
            if (r - l + 1 > maxLen) { start = l; maxLen = r - l + 1; }
            l--; r++;
        }
    }
}
```

### 三种字符串 DP 对比
| | 最长公共子串 | 最长公共子序列 | 最长回文子串 |
|--|------------|--------------|------------|
| 要求 | 连续 | 不连续 | 连续 |
| DP 方程 | s[i]==s[j] -> dp[i-1][j-1]+1; else 0 | s[i]==s[j] -> dp[i-1][j-1]+1; else max(dp[i-1][j], dp[i][j-1]) | s[i]==s[j] && (j-i<2 or dp[i+1][j-1]) |
| 结果 | dp 数组中最大值 | dp[m][n] | 所有 true 的 dp[i][j] 中最长 |
| 最优解 | DP O(mn) / 后缀树 O(m+n) | DP O(mn) | 中心扩展 O(n^2) / Manacher O(n) |

## 💬 面试官常见追问
- "最长公共子串和最长公共子序列的区别？" -> 子串连续（不等清零），子序列不连续（可取 max 跳）
- "最长回文子串除了中心扩展还有什么解法？" -> DP O(n^2)、Manacher O(n)
- "如何输出最长公共子串的实际内容？" -> 记录 maxLen 的同时记录结束位置，最后 `s1.substr(end-maxLen, maxLen)`

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：最长公共子串的 DP 方程写成 LCS 的写法（不等时取 max）。正确是清零
- **误区**：中心扩展法只考虑了奇数长度。忘了偶数长度回文（中心是两个字符之间）
