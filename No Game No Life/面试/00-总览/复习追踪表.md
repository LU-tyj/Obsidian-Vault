# 复习追踪表

> **总进度**：153 篇 / 153 篇待复习

## 怎么用这个表

1. **学完一篇** → 把 `状态` 改为 `reviewing`，填 `首次学习` 日期，然后说"同步一下复习进度"让脚本回写 frontmatter
2. **复习一篇** → `复习次数 +1`，`上次复习` 填今天日期，按掌握情况改 `状态`
3. **脱稿讲清** → 状态改为 `mastered`

**状态说明**：
- `new` — 还没看过
- `reviewing` — 看过但讲不清标准答案
- `mastered` — 可脱稿讲清 2 分钟标准答案 + 应对追问

**复习间隔**（脚本自动计算 `下次复习` 的依据）：

| 复习次数 | 1 | 2 | 3 | 4 | 5+ |
|----------|---|---|---|---|----|
| 间隔（天） | 1 | 3 | 7 | 15 | 30 |

> **工作流**：手动改此表 → 跟 Claude Code 说"同步一下复习进度" → 脚本自动回写笔记 frontmatter + 算下次复习日期 + 更新统计面板 + 生成待复习清单。

1. **学新课**：按 [[复习计划]] 学完笔记 → 在本表把状态改为 `reviewing`，填首次学习日期
2. **复习旧课**：打开本表 → 找 `状态 = reviewing` 且 `上次复习` 较久远的 → 自测 → 改状态/复习次数/上次复习
3. **同步**：跟 Claude Code 说"同步一下复习进度" → 脚本自动回写 frontmatter + 算下次复习 + 更新统计 + 生成待复习清单

### 每周检查
- 每周末看统计面板，确保 `mastered` 比例在上升
- 如果某个专题 `reviewing` 占比过高（>50%），下周优先复习该专题
