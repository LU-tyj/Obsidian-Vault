## 例1：tree
当你环境中有一堆树的时候，每个树有包括几何、纹理、颜色、高度、厚度、位置等多种属性。
```cpp
class tree
{
private:
	Mesh mesh_;
	Texture bark_;
	Texture leaves_;
	Vector position_;
	double height_;
	double thickness_;
	Color barkTint_;
	Color leafTint_;
}
```
如果对每整个森林的每个树都存储这么多的变量，那么会占用很多的内存。
我们发现：不同树的 `mesh, bark_, leaves_` 这些都是不变的，因此我们可以把它分离出来，让所有其他树只存储指向这个类的指针。
```cpp
class TreeModel
{
private:
	Mesh mesh_;
	Texture bark_;
	Texture leaves_;
}
```

这样之后树的类可以写为
```cpp
class tree
{
private:
	TreeModel* model_;
	
	Vector position_;
	double height_;
	double thickness_;
	Color barkTint_;
	Color leafTint_;
}
```

## 例2：world
“There can be patches of grass, dirt, hills, lakes, rivers, and whatever other terrain you can dream up. We’ll make the ground _tile-based_: the surface of the world is a huge grid of tiny tiles. Each tile is covered in one kind of terrain.

Each terrain type has a number of properties that affect gameplay:

- A movement cost that determines how quickly players can move through it.
- A flag for whether it’s a watery terrain that can be crossed by boats.
- A texture used to render it.
”
一个简单粗暴的方法是：`enum` 创造不同 terrain 种类 -> 世界为 `Terrain tile_[WIDTH][HEIGHT]` -> 使用 `switch case` 去进行分别判断

==当 switch case 非常多的时候，就可以考虑 享元模式==
![[Flyweight_terrain.png]]

代码如下：
```cpp
class Terrain
{
public:
  Terrain(int movementCost,
          bool isWater,
          Texture texture)
  : movementCost_(movementCost),
    isWater_(isWater),
    texture_(texture)
  {}

  int getMovementCost() const { return movementCost_; }
  bool isWater() const { return isWater_; }
  const Texture& getTexture() const { return texture_; }

private:
  int movementCost_;
  bool isWater_;
  Texture texture_;
};
```

```cpp
class World
{
public:
  World()
  : grassTerrain_(1, false, GRASS_TEXTURE),
    hillTerrain_(3, false, HILL_TEXTURE),
    riverTerrain_(2, true, RIVER_TEXTURE)
  {}

private:
  Terrain grassTerrain_;
  Terrain hillTerrain_;
  Terrain riverTerrain_;

  // Other stuff...
  Terrain* tiles_[WIDTH][HEIGHT];
};
```

生成世界的代码：
```cpp
void World::generateTerrain()
{
	for (int x = 0; x < WIDTH; x++ )
	{
		for (int y = 0; y < HEIGHT; y++)
		{
			if (random(10) == 0)
			{
				tiles_[x][y] = &hillTerrain_;
			}
			else
			{
				tiles_[x][y] = &grassTerrain_;
			}
		}
	}
	

	int x = random(WIDTH);
	for (int y = 0; y < HEIGHT; y++) 
	{
	    tiles_[x][y] = &riverTerrain_;
	}
}


const Terrain& World::getTile(int x, int y) const
{
  return *tiles_[x][y];
}
```

这样就可以使 `World` 不与其他地形耦合（一堆 `switch case`），可以直接通过块的本身来获取
```cpp
int cost = world.getTile(2, 3).getMovementCost();
```
