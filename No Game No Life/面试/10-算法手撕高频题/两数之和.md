## 🎯 一句话结论（自测用）
> 无序数组找两数和 = target：哈希表 O(n)（存 target-num 的历史值）。有序数组：双指针 O(n)（left++ right--）。三数和/四数和：排序 + 双指针 O(n^2)/O(n^3)。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **无序数组两数之和**：遍历时检查 `target - num` 是否在哈希表中。在则返回，不在则把 `(num, index)` 插入哈希表。O(n)
2. **有序数组两数之和**：双指针 `l=0, r=n-1`。`sum < target` 则 l++，`sum > target` 则 r--。O(n)
3. **三数之和**：排序 + 固定一个 + 双指针找两数之和。O(n^2)，注意去重
4. **四数之和**：排序 + 固定两个 + 双指针。O(n^3)，或用哈希表 O(n^2)

## 🔍 详细解析

### 两数之和（无序，LeetCode 1）
```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> map;  // value -> index
    for (int i = 0; i < nums.size(); i++) {
        int complement = target - nums[i];
        if (map.count(complement))
            return {map[complement], i};
        map[nums[i]] = i;
    }
    return {};
}
```

### 两数之和（有序，LeetCode 167）
```cpp
vector<int> twoSumSorted(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int sum = nums[l] + nums[r];
        if (sum == target) return {l + 1, r + 1};
        else if (sum < target) l++;
        else r--;
    }
    return {};
}
```

### 三数之和（LeetCode 15）
```cpp
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());
    vector<vector<int>> res;
    int n = nums.size();
    
    for (int i = 0; i < n - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue;  // 去重
        if (nums[i] > 0) break;  // 剪枝：最小的都 >0 不可能和为 0
        
        int l = i + 1, r = n - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                res.push_back({nums[i], nums[l], nums[r]});
                while (l < r && nums[l] == nums[l + 1]) l++;  // 去重
                while (l < r && nums[r] == nums[r - 1]) r--;  // 去重
                l++; r--;
            } else if (sum < 0) l++;
            else r--;
        }
    }
    return res;
}
```

### 面试变体：无序数组两数和等于 target（面经 013_Q21）
```cpp
// 要求 O(n)，返回 true/false 或索引即可
bool hasTwoSum(vector<int>& nums, int target) {
    unordered_set<int> seen;
    for (int x : nums) {
        if (seen.count(target - x)) return true;
        seen.insert(x);
    }
    return false;
}
```

// 两数之和
public int[] TwoSum(int[] nums, int target)
{
    var map = new Dictionary<int, int>();
    for (int i = 0; i < nums.Length; i++)
    {
        int complement = target - nums[i];
        if (map.TryGetValue(complement, out int idx))
            return new[] { idx, i };
        map[nums[i]] = i;
    }
    return Array.Empty<int>();
}

## 💬 面试官常见追问
- "两数之和如果要求返回所有不重复的对（不是索引）怎么做？" -> 排序 + 双指针 + 去重
- "三数之和接近 target 怎么做？" -> 排序 + 双指针，差值最小的时候更新结果
- "无序数组 O(n) 解法用了 O(n) 空间，能 O(1) 空间吗？" -> 排序 + 双指针可以 O(1) 额外空间，但 O(nlogn) 时间

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：两数之和先用哈希表存所有元素再遍历。边遍历边存更简洁，且能处理重复元素（如 `[3,3], target=6`）
- **误区**：三数之和忘了去重。会导致重复结果，面试直接扣分
- **误区**：双指针的移动条件搞反。`sum < target` 时应该 `l++`（让和变大），`sum > target` 时 `r--`（让和变小）
