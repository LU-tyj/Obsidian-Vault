## 🎯 一句话结论（自测用）
> 战斗系统核心包括：碰撞检测（伤害判定）、技能释放/冷却、伤害计算与 Buff/Debuff 管理。碰撞检测的优化方式从简单到复杂：暴力遍历 O(n^2) -> 空间分区（八叉树/四叉树/网格）-> 物理引擎碰撞事件。网易互娱面试中常以场景题出现：武器挥动伤害判定、炸弹爆炸范围判定、空投圆形随机取点。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **武器挥动碰撞检测**（近战攻击）：
   - 在武器上挂载 Collider（设为 Trigger），挥动时开启/关闭
   - 每帧检查 OnTriggerEnter 事件
   - 优化：使用 OverlapSphere/OverlapBox 一次检测替代逐帧 Trigger，减少物理开销
   - 注意同一目标多次命中去重（用 HashSet 记录已命中目标）
2. **炸弹爆炸范围判定**（AOE 伤害）：
   - 使用 Physics.OverlapSphere(爆炸中心, 半径, LayerMask)
   - 大量怪物场景优化：先用空间分区（四叉树/八叉树）粗筛，再精确检测
   - 爆炸伤害衰减：按距离计算伤害系数
3. **圆形区域随机空投**：
   - 问题：在半径为 R 的圆内等概率随机取点
   - 误区：直接随机 r 和 theta 会导致圆心附近概率高（面积不均匀）
   - 正确做法：r = sqrt(random) * R, theta = random * 2*PI（按面积比例随机半径）
4. **大面积碰撞检测优化**（如百万个矩形快速碰撞）：
   - 空间分区：四叉树（2D）/八叉树（3D）/均匀网格
   - 扫掠线算法（Sweep and Prune）
   - 分治 + 范围查询

## 🔍 详细解析

### 武器碰撞检测去重
```csharp
private HashSet<GameObject> hitTargets = new();
void OnEnable() { hitTargets.Clear(); }  // 每次挥动重置
void OnTriggerEnter(Collider other) {
    if (!hitTargets.Contains(other.gameObject)) {
        hitTargets.Add(other.gameObject);
        other.GetComponent<Health>()?.TakeDamage(damage);
    }
}
```

### 圆形区域等概率随机取点
```csharp
// 正确做法：按面积分配
float angle = Random.Range(0f, 2f * Mathf.PI);
float radius = Mathf.Sqrt(Random.Range(0f, 1f)) * maxRadius;
Vector2 point = center + new Vector2(
    radius * Mathf.Cos(angle),
    radius * Mathf.Sin(angle)
);
```
原理：圆面积 = PI * R^2，半径 r 处的圆环面积为 2*PI*r*dr，与 r 成正比。要让每个面积微元概率均等，半径的平方应均匀分布。

### 碰撞检测优化层级
1. **粗筛**：空间分区 / 四叉树 / 八叉树 -> 减少候选对
2. **包围盒检测**：AABB 快速相交测试 -> 精确碰撞前的廉价过滤
3. **精确检测**：OBB / 凸包 / 三角形检测 -> 只有必要时才做

## 💬 面试官常见追问
- **为什么圆形随机直接用 Random.Range(0,R) 取半径是错误的？** → 圆心附近面积占比小但半径范围占比大，导致不均匀
- **OverlapSphere 和 OnTriggerEnter 的选择？** → OverlapSphere 一次检测、CPU 开销可控；OnTriggerEnter 持续检测、适合需要持续追踪的场景
- **碰撞检测的性能瓶颈在哪里？** → 暴力遍历 O(n^2) 的候选对筛选；优化重点在粗筛阶段降低候选对数量

## ⚠️ 我曾经的误区 / 网上常见错答
- 误区：圆形随机取点就是随机半径 + 随机角度。圆心附近会非常密集
- 误区：武器碰撞用 OnCollisionEnter。OnCollisionEnter 需要 Rigidbody，用 OnTriggerEnter 更轻量
