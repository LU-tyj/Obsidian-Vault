## 🎯 一句话结论（自测用）
> 栈 = LIFO（括号匹配/函数调用/撤销），队列 = FIFO（BFS/消息队列）。循环队列用数组实现，空满判断用 (rear+1)%capacity==front。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **栈（Stack）**：后进先出（LIFO）。push/pop/top。应用：括号匹配、函数调用栈、撤销操作、DFS
2. **队列（Queue）**：先进先出（FIFO）。enqueue/dequeue/front。应用：BFS、消息队列、生产者消费者
3. **循环队列**：用固定大小数组实现队列，头尾指针循环使用。判空：`front == rear`；判满：`(rear+1) % capacity == front`（浪费一个位置）
4. **括号匹配**：遍历字符串，左括号入栈，右括号检查栈顶是否匹配。最后栈为空则匹配
5. **支持查询最大值的队列**：用辅助双端队列维护最大值（单调队列），入队时弹出队尾所有小于新元素的元素

## 🔍 详细解析

### 循环队列实现
```cpp
class CircularQueue {
    vector<int> data;
    int front, rear, cap;
public:
    CircularQueue(int k) : data(k), front(0), rear(0), cap(k) {}
    
    bool enQueue(int val) {
        if (isFull()) return false;
        data[rear] = val;
        rear = (rear + 1) % cap;
        return true;
    }
    
    bool deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % cap;
        return true;
    }
    
    int Front() { return isEmpty() ? -1 : data[front]; }
    int Rear() { return isEmpty() ? -1 : data[(rear - 1 + cap) % cap]; }
    bool isEmpty() { return front == rear; }
    bool isFull() { return (rear + 1) % cap == front; }
};
```

### 括号匹配
```cpp
bool isValid(string s) {
    stack<char> st;
    unordered_map<char, char> pairs = {{')','('}, {']','['}, {'}','{'}};
    for (char c : s) {
        if (pairs.count(c)) {
            if (st.empty() || st.top() != pairs[c]) return false;
            st.pop();
        } else st.push(c);
    }
    return st.empty();
}
```

### 支持查询最大值的队列（单调队列）
```cpp
class MaxQueue {
    queue<int> q;
    deque<int> maxDeque;  // 单调递减，front 为最大值
public:
    void push(int x) {
        q.push(x);
        while (!maxDeque.empty() && maxDeque.back() < x)
            maxDeque.pop_back();
        maxDeque.push_back(x);
    }
    void pop() {
        if (q.front() == maxDeque.front())
            maxDeque.pop_front();
        q.pop();
    }
    int max() { return maxDeque.front(); }
};
```
面试场景题：实现队列支持查询最大值 -> 按值查找位置 -> 任意位置删除。

### 栈与队列面试对比表
| | 栈 | 队列 |
|--|----|------|
| 原则 | LIFO | FIFO |
| 操作 | push/pop/top | enqueue/dequeue/front |
| 应用 | 括号匹配、DFS、函数调用 | BFS、消息队列、循环队列 |
| 实现 | 可用数组/链表 | 可用数组/链表 |

## 💬 面试官常见追问
- "怎样用两个栈实现一个队列？" -> 栈1负责入队，栈2负责出队。出队时若栈2空则把栈1全倒入栈2
- "怎样用两个队列实现一个栈？" -> 每次 push 到空队列，然后把另一个队列的元素全倒过来
- "循环队列为什么要浪费一个位置？" -> 区分队空和队满。`front==rear` 无法区分，所以 `(rear+1)%cap==front` 为满

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：循环队列的判满用 `rear == front`。这和判空一样，会导致无法区分
- **误区**：队列的 Rear() 直接返回 `data[rear]`。入队后 rear 指向下一个空位，实际队尾是 `data[(rear-1+cap)%cap]`
