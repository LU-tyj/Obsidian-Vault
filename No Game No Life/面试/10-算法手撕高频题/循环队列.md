## 🎯 一句话结论（自测用）
> 固定大小数组实现。判空 `front==rear`，判满 `(rear+1)%cap==front`（浪费一位）。所有操作 O(1)。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. 使用数组 + 两个指针 front（队首）和 rear（队尾下一个空位）
2. 入队：`data[rear]=val; rear=(rear+1)%cap`
3. 出队：`front=(front+1)%cap`
4. 判空：`front == rear`
5. 判满：`(rear + 1) % capacity == front`（保留一个空位区分空和满）

## 🔍 详细解析

### C++ 标准实现
```cpp
class MyCircularQueue {
private:
    vector<int> data;
    int front;
    int rear;
    int cap;
    
public:
    MyCircularQueue(int k) : data(k), front(0), rear(0), cap(k) {}
    
    bool enQueue(int value) {
        if (isFull()) return false;
        data[rear] = value;
        rear = (rear + 1) % cap;
        return true;
    }
    
    bool deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % cap;
        return true;
    }
    
    int Front() {
        if (isEmpty()) return -1;
        return data[front];
    }
    
    int Rear() {
        if (isEmpty()) return -1;
        // rear 指向下一个空位，队尾在 rear-1
        return data[(rear - 1 + cap) % cap];
    }
    
    bool isEmpty() { return front == rear; }
    bool isFull() { return (rear + 1) % cap == front; }
};
```

### 不使用"浪费一位"的实现（额外 count 变量）
```cpp
class MyCircularQueue2 {
private:
    vector<int> data;
    int front, rear, count, cap;
    
public:
    MyCircularQueue2(int k) : data(k), front(0), rear(0), count(0), cap(k) {}
    
    bool enQueue(int value) {
        if (isFull()) return false;
        data[rear] = value;
        rear = (rear + 1) % cap;
        count++;
        return true;
    }
    
    bool deQueue() {
        if (isEmpty()) return false;
        front = (front + 1) % cap;
        count--;
        return true;
    }
    
    bool isEmpty() { return count == 0; }
    bool isFull() { return count == cap; }
    // Front() 和 Rear() 同标准实现
};
```

public class MyCircularQueue
{
    private int[] data;

        if (IsFull()) return false;

        rear = (rear + 1) % cap;
        return true;
    }

    public bool DeQueue()
    {
        if (IsEmpty()) return false;
        front = (front + 1) % cap;
        return true;
    }

    public int Front() => IsEmpty() ? -1 : data[front];
    public int Rear() => IsEmpty() ? -1 : data[(rear - 1 + cap) % cap];
    public bool IsEmpty() => front == rear;
    public bool IsFull() => (rear + 1) % cap == front;
}

### 面试进阶：支持查询最大值的队列（面经 007_Q9）
```cpp
class MaxQueue {
    queue<int> q;
    deque<int> maxDeque;  // 单调递减双端队列，front 为最大

public:
    void push(int x) {
        q.push(x);
        // 弹出队尾所有小于 x 的元素
        while (!maxDeque.empty() && maxDeque.back() < x)
            maxDeque.pop_back();
        maxDeque.push_back(x);
    }

    int pop() {
        if (q.empty()) return -1;
        int val = q.front();
        q.pop();
        // 如果弹出的恰好是当前最大值
        if (val == maxDeque.front())
            maxDeque.pop_front();
        return val;
    }

    int max() {
        return maxDeque.empty() ? -1 : maxDeque.front();
    }
};
```

### 循环队列面试要点
| 要点 | 说明 |
|------|------|
| 判空判满的边界条件 | `front==rear` 空，`(rear+1)%cap==front` 满 |
| Rear() 取队尾 | 不是 `data[rear]`，而是 `data[(rear-1+cap)%cap]` |
| 为什么浪费一个位置 | 区分空和满，当 `(rear+1)%cap==front` 时判定为满 |
| 多线程安全的循环队列 | 需要锁或 CAS 原子操作保护 front/rear |

## 💬 面试官常见追问
- "循环队列为什么要浪费一个位置？" -> 区分判空和判满。满时 rear+1==front（mod cap），空时 rear==front
- "有没有不浪费位置的方法？" -> 增加 count 变量，或使用 bool 标记。但增加额外维护成本
- "多线程下循环队列有什么问题？" -> 多个线程同时读写 front/rear 需要加锁。可用无锁队列（lock-free queue）优化

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：`Rear()` 返回 `data[rear]`。rear 指向的是下一个空位，队尾是 `(rear-1+cap)%cap`
- **误区**：判满用 `rear == front`。和判空一模一样，无法区分
- **误区**：扩容条件写成 `rear == cap`。循环队列的 rear 一直在 [0, cap) 范围内循环
