## 🎯 一句话结论（自测用）
> 链表题核心三板斧：快慢指针（找中点/判环）、双指针（反转/公共节点）、递归（LCA/归并排序）。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **反转链表**：迭代法（pre/cur/next 三指针），递归法（返回新头节点）
2. **找环**：快慢指针，相遇则有环；找环入口：相遇后慢指针回头，同速再次相遇点即入口
3. **链表公共子节点**：双指针分别遍历 A+B 和 B+A，首次相等即为交点
4. **LCA（最近公共祖先）**：二叉树递归，若 root 等于 p 或 q 则返回 root，否则递归左右子树；左右都非空则 root 是 LCA
5. **链表归并排序**：快慢指针找中点 -> 递归排序左右 -> 合并两个有序链表（O(nlogn)，空间 O(logn)）

## 🔍 详细解析

### 反转链表（迭代法）
```
pre = null, cur = head
while (cur) {
    next = cur.next;
    cur.next = pre;
    pre = cur;
    cur = next;
}
return pre;
```
时间复杂度 O(n)，空间 O(1)。

### 链表找环（Floyd 判圈算法）
- **判环**：slow 走一步，fast 走两步。相遇则有环，fast 到 null 则无环
- **找入口**：相遇后将 slow 指向 head，fast 保持，两者同速走，再次相遇点即环入口
- **原理**：设链表头到入口距离 a，入口到相遇点 b，相遇点到入口 c。有 2(a+b) = a+b+c+b => a=c

### 两个链表求公共子节点
```cpp
ListNode *pA = headA, *pB = headB;
while (pA != pB) {
    pA = (pA == NULL) ? headB : pA->next;
    pB = (pB == NULL) ? headA : pB->next;
}
return pA;  // 可能为 NULL（无交点）
```
时间复杂度 O(m+n)，空间 O(1)。核心思想：消除长度差。

### 链表归并排序
1. 快慢指针找中点，断开链表
2. 递归排序左半和右半
3. 合并两个有序链表
时间复杂度 O(nlogn)，空间 O(logn)（递归栈）。

## 💬 面试官常见追问
- "链表和数组的区别？" -> 内存连续 vs 非连续，随机访问 O(1) vs O(n)，插入删除 O(n) vs O(1)
- "链表判环为什么快指针走两步不走三步？" -> 两步保证在环内一定相遇（每次缩小距离 1），三步可能跳过
- "能用哈希表判环吗？" -> 可以，但 O(n) 空间。快慢指针 O(1) 空间更优

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：反转链表只记住迭代法，递归写不出来。递归返回新头，cur.next.next = cur; cur.next = null
- **误区**：公共子节点用哈希表存储 A 的所有节点。O(n) 空间太浪费，双指针 O(1) 空间为最优解
