## 一句话结论（自测用）
> 碰撞三条件：两物体都有 Collider + 至少一方有 Rigidbody。碰撞三回调：OnCollisionEnter/Stay/Exit（物理碰撞），OnTriggerEnter/Stay/Exit（触发器检测）。Raycast 优化：用 LayerMask + NonAlloc 方法 + 控制距离。

## 标准答案（结构化、可背诵，2分钟内讲完）
1. **碰撞发生的必要条件**：
   - 两个物体都必须有 **Collider** 组件
   - 至少其中一个物体有 **Rigidbody** 组件
   - 两个物体都在物理层中（且层级之间的碰撞矩阵未禁用）
2. **碰撞回调（Collision）vs 触发器（Trigger）**：
   - **Collision**：物理反馈（弹开、停止）、产生 `Collision` 对象（含碰撞点/法线/冲量等）
     - `OnCollisionEnter / Stay / Exit`
   - **Trigger**：仅检测进入/离开，不产生物理反馈
     - `OnTriggerEnter / Stay / Exit`
     - 开启：勾选 Collider 的 `Is Trigger`
3. **Rigidbody 的角色**：
   - 静态 Collider（无 Rigidbody）：不参与物理模拟，仅做碰撞检测
   - 运动学 Rigidbody（`isKinematic = true`）：可碰撞但不受力影响，由代码控制移动
   - 非运动学 Rigidbody：受重力、受力、碰撞反馈影响
4. **Raycast 优化四条**：
   - `LayerMask`：只检测特定层，减少不必要的对象
   - `Physics.RaycastNonAlloc`：用预分配数组避免 GC
   - `maxDistance`：限制检测距离
   - `QueryTriggerInteraction.Ignore`：忽略触发器

## 详细解析

### Collider 类型选择
| Collider 类型 | CPU 开销 | 适用 |
|-------------|---------|------|
| Sphere | 最低 | 球形物体、粗略碰撞 |
| Capsule | 低 | 人物碰撞体 |
| Box | 低 | 方形物体 |
| Mesh Collider（Convex） | 中等 | 需要精确形状 |
| Mesh Collider（非 Convex） | **极高** | 仅与静态 Mesh Collider 碰撞 |

面试常问：为什么 Mesh Collider 要勾选 Convex？（非 Convex 的 Mesh Collider 不支持 Rigidbody，只能用于静态物体。Convex 使用更简单的凸包近似，性能更好。）

### Rigidbody 的 Interpolate / Extrapolate
- **Interpolate**：根据上一帧位置平滑（适合被物理驱动的物体，如角色）
- **Extrapolate**：根据当前速度预测位置（适合高速物体）
- 解决物理抖动问题

### FixedUpdate 的时间步
```csharp
// 默认 0.02s = 50Hz
Time.fixedDeltaTime = 0.02f;

// FixedUpdate 可能在一帧内多次执行（追赶物理时间）
// 物理计算不应放在 Update 中
```

### 射线检测的 NonAlloc 版本
```csharp
// 差：每帧分配 RaycastHit[] 数组
RaycastHit[] hits = Physics.RaycastAll(ray, 100f);

// 好：预分配数组，零 GC
RaycastHit[] hitBuffer = new RaycastHit[32]; // 复用
int hitCount = Physics.RaycastNonAlloc(ray, hitBuffer, 100f);
for (int i = 0; i < hitCount; i++) { ... }
```

## 面试官常见追问
- IsKinematic 和 Static Collider 的区别？（Kinematic 可以代码移动且参与碰撞检测，Static 完全不能移动）
- OnTriggerStay 在什么时候调用？（每个 FixedUpdate 中，只要 Trigger 区域内有其他 Collider）
- 为什么移动 Kinematic Rigidbody 要用 MovePosition 而非 Transform.position？（MovePosition 保证碰撞检测正确，直接改 transform 可能穿模）
