## 1 Introduction
**原型模式**通过复制（clone）已有对象来创建新对象，而不是通过 `new` + 构造函数。
可以显著节省在 load 图片等时的成本。

---

## 2 Examples
我们打算创建多种种类的怪物及其生成器

### 2.1 原型模式实现
“原型模式提供了一种解决方案。其核心思想是一个对象可以生成与自身相似的其他对象。如果你有一个幽灵，则你可以通过这个幽灵制作出更多的幽灵。如果你有一个魔鬼，那你就能制作出其他魔鬼。任何怪物都能被看作是一个原型，用这个原型就可以复制出更多不同版本的怪物。”

1. `Monster` 基类以及`clone`函数
```cpp
class Monster
{
public:
	virtual ~Monster() {};
	virtual Monster* clone() = 0;
}
```

2. 子类实现能返回一个与自身属性相同的对象
```cpp
class Ghost : public Monster {
public:
  Ghost(int health, int speed)
  : health_(health),
    speed_(speed)
  {}

  virtual Monster* clone()
  {
    return new Ghost(health_, speed_);
  }

private:
  int health_;
  int speed_;
};
```
>这里的例子可能不是很明显原型模式的好处，但后面会体现

3. 不用为每一个怪物定义一个生成器，只需要定义一个总的生成器
```cpp
class Spawner
{
public:
  Spawner(Monster* prototype)
  : prototype_(prototype)
  {}

  Monster* spawnMonster()
  {
    return prototype_->clone();
  }

private:
  Monster* prototype_;
};
```

这样只需要 **创建原型** + **创建生成器** 就可以了
```cpp
Monster* ghostPrototype = new Ghost(15, 3);
Spawner* ghostSpawner = new Spawner(ghostPrototype);
```

### 2.2 其他实现方式
有很多其他的实现方式（特定情况特定使用），比如下面的**生成器函数**、**模版**……

```cpp
Monster* spawnGhost()
{
	return new Ghost();
}

typedef Monster* (*SpawnCallback)();
class Spawner
{
public:
	Spawner(SpawnCallback spawn)
	: spawn_(spawn)
	{}

	Monster* spawnMonster()
	{
		return spawn_();
	}

private:
	SpawnCallback spawn_;

};


Spawner* ghostSpawner = new Spawner(spawnGhost);
```

## 3 使用原型模式来进行数据建模
游戏数据一半存储在 json 文件中，但是如果对很多小怪物都存储全部属性的话会造成 json 文件很长又很复杂，所以可以使用原型来存储。

```json
{
  "name": "goblin grunt",
  "minHealth": 20,
  "maxHealth": 30,
  "resists": ["cold", "poison"],
  "weaknesses": ["fire", "light"]
}

{
  "name": "goblin wizard",
  "prototype": "goblin grunt",
  "spells": ["fire ball", "lightning bolt"]
}

{
  "name": "goblin archer",
  "prototype": "goblin grunt",
  "attacks": ["short bow"]
}
```
