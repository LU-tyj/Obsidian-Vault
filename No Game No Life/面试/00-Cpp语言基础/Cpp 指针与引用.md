## 一句话结论（自测用）
> 指针是变量存地址，可为空、可重新指向、可进行算术运算；引用是别名，必须初始化、不可为 null、不可重新绑定。函数参数选引用（安全语义），需要"不指向任何对象"或"改变所指对象"时选指针。

## 标准答案（结构化、可背诵，2分钟内讲完）
1. **定义差异**：指针是一个变量，存储另一个变量的地址；引用是一个别名，与原变量共享同一块内存。
2. **关键区别**：
   - 指针可以不初始化；引用必须在声明时初始化
   - 指针可以为 nullptr；引用不能为 null（虽然可以写出指向 nullptr 的引用但 UB）
   - 指针可以重新指向其他对象；引用一经绑定不可更改
   - 指针有顶层 const（`int* const p`）和底层 const（`const int* p`）；引用只有底层 const
   - sizeof 指针 = 8 字节（64位）；sizeof 引用 = 被引用类型大小
3. **使用场景**：
   - 引用优先用于函数参数（安全，无需判空）
   - 指针用于需要"空"语义、多态、或需要改变指向的场景
4. **底层实现**：引用在编译器层面通常用指针实现（不占独立内存时），但语义上不可为空。

## 详细解析

### 常量指针 vs 指针常量（高频混淆题）
```cpp
const int* p1;       // 常量指针：指向常量的指针，不能改 *p1，能改 p1
int* const p2;       // 指针常量：指针本身是常量，能改 *p2，不能改 p2
const int* const p3; // 都不可以改
```

助记：从右往左读。`p2 is a const pointer to int`（p2 本身是 const 的指针）。

### 引用作为函数返回值
返回引用可用于链式调用（如 `cout << a << b` 返回 `ostream&`）。**绝对不能返回局部变量的引用**——函数返回后栈变量已销毁，引用变成悬垂引用。

### 多态中的指针与引用
两者都支持多态。区别：指针可为 nullptr（需要判空），引用不行；指针可以 `delete`，引用不行。

## 面试官常见追问
- 引用的底层实现是什么？（编译器通常用指针实现，但标准未规定具体实现方式）
- 函数参数什么时候用指针什么时候用引用？（引用：需要修改实参且不需要判空；指针：可能为空、需要多态、或 C 风格 API）
- "引用不可为 null" 是真的一定吗？（标准规定引用必须绑定到合法对象，但可以写出 `int& r = *(int*)nullptr;` 这种 UB 代码）
- 成员函数指针和普通函数指针有什么区别？（成员函数指针大小不是 8 字节，包含 this 偏移量、虚表索引等信息）

## 我曾经的误区 / 网上常见错答
- **错**："引用不占内存" —— 底层实现通常是占用存储的（编译器用指针），sizeof 引用返回的是原类型大小不是引用本身大小
- **错**："引用比指针快" —— 底层实现相同，性能无差异
- **错**："引用就是指针的语法糖" —— 语义层面不同（不可为空、不能改绑定），有更强的契约
