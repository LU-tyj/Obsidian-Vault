_Allow the flexible creation of new “classes” by creating a single class, each instance of which represents a different type of object._

## 1 Motivation
当我们在开发一个RPG游戏时，我们可能会制作上百上千种怪物，如果给每一个怪物都一个类别，那么会产生非常多的代码，难以调试，以及一个小的修改（比如增加dragon的health）都会需要很久的编译时间。因此我们把 **类型作为一个类** 进行拓展和维护。这样我们的Monster类不需要很多子类，只需要一个 `MonsterType` 的属性就好了。

类对象模式就是定义一个类型对象类（`MonsterType`）和一个持有类型对象类（`Monster`）。每个类型对象的实例表示一个不同的逻辑类型（比如`dragon`）。每个持有类型对象类的实例引用一个描述其类型的类型对象。

---

## 2 When and how to use it
“当你需要定义一系列不同“种类”的东西，但又不想把那些种类硬编码进你的类型系统时，本模式都适用。尤其是当下面任何一项成立的时候：
- 你不知道将来会有什么类型（例如，我们的游戏是否需要支持包含怪物新种类的资料包下载？）。
- 你需要在不重新编译或修改代码的情况下，修改或添加新的类型。

“

这个方法把生硬的代码语言转移到灵活却弱化了行为的内存对象中，变成数据的形式。也带来了一些问题：
- **类型对象必须手动跟踪**
	当你创建了Monster，你必须同时要创建需要的所有MonsterType实例。
- **为每个类型定义行为更为困难**
	通过类派生，可以很方便进行方法的重写。但这里你必须在成员变量中写好。
	解决方法有使用[[4.1 Bytecode]]中的字节码模式，或者创建一个固定的预定义行为集合。

---

## 3 Sample
1. **核心思想**
这是普通的类型对象（种族）
```cpp
class Breed
{
public:
  Breed(int health, const char* attack)
  : health_(health),
    attack_(attack)
  {}

  int getHealth() { return health_; }
  const char* getAttack() { return attack_; }

private:
  int health_; // Starting health.
  const char* attack_;
};
```

Monster 通过将其作为属性进行使用
```cpp
class Monster
{
public:
  Monster(Breed& breed)
  : health_(breed.getHealth()),
    breed_(breed)
  {}

  const char* getAttack()
  {
    return breed_.getAttack();
  }

private:
  int    health_; // Current health.
  Breed& breed_;
};
```

2. **面向对象**的思想是调用类自身的构造函数，由它负责为我们创建新的实例
```cpp
class Breed
{
public:
  Monster* newMonster() { return new Monster(*this); }

  // Previous Breed code...
};
```

然后用它们的类
```cpp
class Monster
{
  friend class Breed;

public:
  const char* getAttack() { return breed_.getAttack(); }

private:
  Monster(Breed& breed)
  : health_(breed.getHealth()),
    breed_(breed)
  {}

  int health_; // Current health.
  Breed& breed_;
};
```
>这和原本的有什么区别呢？
>初始化时，前者为 `Monster* monster = new Monster(someBreed);`
>后者为`Monster* monster = someBreed.newMonster();`
>看上去没什么区别，但创建一个对象分为分配内存和初始化这两步。在游戏内存分配时，我们在调用怪物的构造函数前，就已经获得一段用于存储 Breed 的内存，但我们有是需要控制对象创建的内存分配，而后者就让我们实现这样的逻辑，

3. **通过继承来共享数据**
我们如果要对每个龙进行数值调整的话，还是会很麻烦，所以我们来实现一种种族之间的继承。
```cpp
class Breed
{
public:
  Breed(Breed* parent, int health, const char* attack)
  : parent_(parent),
    health_(health),
    attack_(attack)
  {}

  int         getHealth();
  const char* getAttack();

private:
  Breed*      parent_;
  int         health_; // Starting health.
  const char* attack_;
};
```

我们可以通过 `parent_` 来获取其基础种族。然后判断是否共享的内存。
在构造时我们可以进行继承：
```cpp
Breed(Breed* parent, int health, const char* attack)
: health_(health),
  attack_(attack)
{
  // Inherit non-overridden attributes.
  if (parent != NULL)
  {
    if (health == 0) health_ = parent->getHealth();
    if (attack == NULL) attack_ = parent->getAttack();
  }
}
```
这样之后就没基类什么事了，我们直接从他那获取了基本数值。

我们就可以实现制改变 Dragon 这个类型的血量，从而改变无数种龙的血量。
