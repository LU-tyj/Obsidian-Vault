## 🎯 一句话结论（自测用）
> 0/1 背包：`dp[j] = max(dp[j], dp[j-w[i]]+v[i])` 逆序遍历 j。完全背包：正序遍历。子集和问题：`dp[j] = dp[j] || dp[j-nums[i]]`。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **0/1 背包**：每个物品最多取一次。一维 DP：`dp[j] = max(dp[j], dp[j-w]+v)`，**j 必须从大到小遍历**
2. **完全背包**：每个物品无限次。一维 DP：`dp[j] = max(dp[j], dp[j-w]+v)`，**j 从小到大遍历**
3. **子集和（能否凑出 target）**：`dp[j] = dp[j] || dp[j-num]`，逆序（0/1 背包变体）
4. 时间复杂度 O(n*target)，空间可优化到 O(target)

## 🔍 详细解析

### 0/1 背包（每个物品最多一次）
```cpp
int knapsack01(vector<int>& weights, vector<int>& values, int capacity) {
    int n = weights.size();
    vector<int> dp(capacity + 1, 0);
    
    for (int i = 0; i < n; i++) {
        // 关键：j 从大到小，保证每个物品只用一次
        for (int j = capacity; j >= weights[i]; j--) {
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

### 完全背包（每个物品无限次）
```cpp
int knapsackComplete(vector<int>& weights, vector<int>& values, int capacity) {
    int n = weights.size();
    vector<int> dp(capacity + 1, 0);
    
    for (int i = 0; i < n; i++) {
        // 关键：j 从小到大，允许同一物品多次使用
        for (int j = weights[i]; j <= capacity; j++) {
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i]);
        }
    }
    return dp[capacity];
}
```

**为什么 0/1 背包逆序、完全背包正序？**
- 逆序：当前轮次的 dp[j-weights[i]] 尚未被当前物品更新，保证每个物品只算一次
- 正序：当前轮次的 dp[j-weights[i]] 可能已被当前物品更新，允许重复使用

### 子集和问题（能否凑出 target）
```cpp
bool canPartition(vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum % 2 != 0) return false;
    int target = sum / 2;
    
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    
    for (int num : nums) {
        for (int j = target; j >= num; j--) {  // 逆序
            dp[j] = dp[j] || dp[j - num];
        }
    }
    return dp[target];
}
```

### 面试变体：子集和为 m 且乘积最大
```cpp
// 思路：二维 DP，dp[i][j] 表示前 i 个元素凑出和为 j 的最大乘积
int maxProductWithSum(vector<int>& nums, int target) {
    int n = nums.size();
    vector<vector<int>> dp(n + 1, vector<int>(target + 1, -1));
    dp[0][0] = 1;  // 空集乘积为 1
    
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= target; j++) {
            dp[i][j] = dp[i-1][j];  // 不取第 i 个
            if (j >= nums[i-1] && dp[i-1][j-nums[i-1]] != -1) {
                dp[i][j] = max(dp[i][j], dp[i-1][j-nums[i-1]] * nums[i-1]);
            }
        }
    }
    return dp[n][target];
}
```

### Csharp 版本（0/1 背包）
```csharp
public int Knapsack01(int[] weights, int[] values, int capacity)
{
    int[] dp = new int[capacity + 1];
    for (int i = 0; i < weights.Length; i++)
        for (int j = capacity; j >= weights[i]; j--)
            dp[j] = Math.Max(dp[j], dp[j - weights[i]] + values[i]);
    return dp[capacity];
}
```

### 背包问题变体一览
| 变体 | DP 方程 | 遍历顺序 |
|------|---------|---------|
| 0/1 背包 | `max(dp[j], dp[j-w]+v)` | j 逆序 |
| 完全背包 | `max(dp[j], dp[j-w]+v)` | j 正序 |
| 多重背包 | 二进制拆分后转0/1 | j 逆序 |
| 子集和 | `dp[j] \|= dp[j-num]` | j 逆序 |
| 硬币找零（最少硬币） | `min(dp[j], dp[j-coin]+1)` | j 正序 |
| 硬币找零（方案数） | `dp[j] += dp[j-coin]` | j 正序 |

## 💬 面试官常见追问
- "为什么 0/1 背包要逆序遍历？" -> 防止同一物品被重复使用。二维 DP 不需要考虑顺序
- "子集和等于背包吗？" -> 是 0/1 背包的特殊情况（重量=值=物品本身）
- "多重背包怎么优化？" -> 二进制拆分：将 k 个物品拆成 1,2,4,... 组，转化为 0/1 背包

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：0/1 背包也正序遍历。会导致物品被重复使用，变成完全背包
- **误区**：子集和 DP 初始化 `dp[0] = true` 就够了。其他初始化为 false（不是 true）
