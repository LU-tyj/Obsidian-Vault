## 🎯 一句话结论（自测用）
> 上楼梯 = 斐波那契：`dp[i] = dp[i-1] + dp[i-2]`。迭代 O(n)/O(1)，递归+记忆化 O(n)/O(n)，裸递归 O(2^n)。面试必须写迭代版！

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **上楼梯（LeetCode 70）**：n 阶楼梯，每次 1 或 2 步。`f(n) = f(n-1) + f(n-2)`
2. **迭代法（最优）**：两个变量滚动，O(n) 时间，O(1) 空间
3. **记忆化递归**：用数组/hash 存储已计算值，O(n) 时间，O(n) 空间
4. **裸递归**：O(2^n)，面试扣分项，必须说明缺陷

## 🔍 详细解析

### 迭代法（推荐面试手写）
```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;  // a = f(1), b = f(2)
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

### 记忆化递归
```cpp
int climbStairs(int n) {
    vector<int> memo(n + 1, -1);
    return dfs(n, memo);
}

int dfs(int n, vector<int>& memo) {
    if (n <= 2) return n;
    if (memo[n] != -1) return memo[n];
    memo[n] = dfs(n - 1, memo) + dfs(n - 2, memo);
    return memo[n];
}
```

### 斐波那契数列

// 经典迭代
int fib(int n) {

public int Fib(int n)
{
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++)
        (a, b) = (b, a + b);
    return b;
}

### 变体题
**每次可走 1~3 步**：
`f(n) = f(n-1) + f(n-2) + f(n-3)`

**有障碍物的路径数（LeetCode 63）**：
```cpp
int uniquePathsWithObstacles(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<long>> dp(m, vector<long>(n, 0));
    dp[0][0] = (grid[0][0] == 0) ? 1 : 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (grid[i][j] == 0) {
                if (i > 0) dp[i][j] += dp[i-1][j];
                if (j > 0) dp[i][j] += dp[i][j-1];
            }
    return dp[m-1][n-1];
}
```

**最小花费爬楼梯（LeetCode 746）**：
```cpp
int minCostClimbingStairs(vector<int>& cost) {
    int n = cost.size();
    int dp0 = 0, dp1 = 0;  // 从第0/1阶开始的花费
    for (int i = 2; i <= n; i++) {
        int cur = min(dp0 + cost[i-2], dp1 + cost[i-1]);
        dp0 = dp1;
        dp1 = cur;
    }
    return dp1;
}
```

## 💬 面试官常见追问
- "斐波那契通项公式能不能用？" -> 可以但不推荐，浮点精度问题导致大数不准确；快速幂矩阵法 O(logn) 更好
- "快速幂矩阵法怎么推导？" -> [F(n), F(n-1)] = [[1,1],[1,0]]^(n-1) * [F(1), F(0)]，矩阵快速幂 O(logn)
- "空间优化到 O(1) 的原理？" -> 只依赖前两个状态，滚动数组

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：用裸递归 `return fib(n-1)+fib(n-2)`。O(2^n) 指数级，n>40 基本卡死
- **误区**：记忆化递归忘记处理 base case。n<=2 时直接返回 n（爬楼梯）或 n（斐波那契 n<=1）
