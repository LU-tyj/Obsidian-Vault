使代码实现需要的功能并不困难，困难的是编写容易应对需求变更的代码。而解耦会让变化简单点。

[Components](https://gameprogrammingpatterns.com/component.html) decouple different domains in your game from each other within a single entity that has aspects of all of them. [Event Queues](https://gameprogrammingpatterns.com/event-queue.html) decouple two objects communicating with each other, both statically and _in time_. [Service Locators](https://gameprogrammingpatterns.com/service-locator.html) let code access a facility without being bound to the code that provides it.
