## 🎯 一句话结论（自测用）
> Fisher-Yates：从右往左，每次从 [0,i] 随机选一个和 i 交换。O(n)，等概率 n! 种排列。关键陷阱：不能每次从全范围随机选。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. 从数组末尾开始，对于每个位置 i：
   - 从 `[0, i]` 中随机选一个索引 j（包含 i）
   - 交换 `arr[i]` 和 `arr[j]`
2. 时间复杂度 O(n)，空间 O(1)
3. 正确性：每个元素出现在每个位置的概率为 1/n，每种排列概率为 1/n!

## 🔍 详细解析

### C++ 标准实现
```cpp
void shuffle(vector<int>& nums) {
    int n = nums.size();
    for (int i = n - 1; i > 0; i--) {
        int j = rand() % (i + 1);  // [0, i]
        swap(nums[i], nums[j]);
    }
}
```

### C++ 现代随机库
```cpp
#include <random>

void shuffleModern(vector<int>& nums) {
    static random_device rd;
    static mt19937 gen(rd());
    
    int n = nums.size();
    for (int i = n - 1; i > 0; i--) {
        uniform_int_distribution<int> dist(0, i);
        int j = dist(gen);
        swap(nums[i], nums[j]);
    }
}
```

### Csharp 版本
```csharp
using System;

public static class Shuffle
{
    private static System.Random rng = new();

    public static void FisherYates<T>(T[] array)
    {
        int n = array.Length;
        for (int i = n - 1; i > 0; i--)
        {
            int j = rng.Next(i + 1);  // [0, i]
            (array[i], array[j]) = (array[j], array[i]);
        }
    }
}
```

### 常见错误做法（不均匀，面试扣分）
```cpp
// 错误！不是均匀分布
for (int i = 0; i < n; i++) {
    int j = rand() % n;  // 每次从全范围选
    swap(nums[i], nums[j]);
}
// 问题：有 n^n 种可能结果，无法均匀映射到 n! 种排列（除非 n^n 能被 n! 整除，实际只有 n=1,2 满足）
```

### 正确性证明思路
- 位置 i 的元素来自哪个索引？等概率来自 [0,i] 中的任意一个（概率 1/(i+1)）
- 用数学归纳法或概率推导：每个元素出现在每个位置的概率恒为 1/n

### 面试变体
**Knuth-Durstenfeld 洗牌 + 删除 3 的倍数**（面经 009_Q15）：
```cpp
// 先洗牌，再删除值为 3 的倍数的元素
void shuffleAndRemove3x(vector<int>& nums) {
    // 1. 洗牌
    int n = nums.size();
    for (int i = n - 1; i > 0; i--) {
        int j = rand() % (i + 1);
        swap(nums[i], nums[j]);
    }
    // 2. 删除 3 的倍数
    nums.erase(remove_if(nums.begin(), nums.end(), 
              [](int x) { return x % 3 == 0; }), nums.end());
}
```

## 💬 面试官常见追问
- "如何证明 Fisher-Yates 是均匀的？" -> 数学归纳法：第 n 个位置每个元素概率 1/n，第 n-1 个位置每个剩余元素概率 1/(n-1)，连乘得 1/n!
- "全范围随机为什么不对？" -> n^n 种结果无法被 n! 均匀整除（除了 n=1,2）-> 存在偏差
- "怎么在面试中表达均匀性证明？" -> 说清楚：每个位置被选中的概率 = 1/(当前剩余元素数)，连乘 = 1/n!

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：洗牌从 i=0 到 n-1 用 `rand() % n`。这是经典错误，面试官一定会追问均匀性
- **误区**：以为 `rand() % (i+1)` 的 `i+1` 可以换成 `n`。`n` 就是全范围了，不公平
- **误区**：C++ 中直接用 `rand()`。rand() 范围有限（RAND_MAX=32767）、质量差，推荐 `<random>` 库
