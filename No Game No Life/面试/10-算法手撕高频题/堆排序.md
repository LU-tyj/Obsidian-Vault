## 🎯 一句话结论（自测用）
> 建堆 O(n) + 反复取堆顶交换到末尾并调整 O(nlogn)。不稳定，空间 O(1)。数组索引关系：父 (i-1)/2，左子 2i+1，右子 2i+2。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **建堆（Heapify）**：从最后一个非叶节点开始自底向上做下沉（siftDown），O(n)
2. **排序**：依次将堆顶（最大值）与末尾交换，然后对剩余元素做下沉，O(nlogn)
3. 大顶堆 -> 升序排列；小顶堆 -> 降序排列
4. 不稳定排序，原地排序（空间 O(1)）
5. 索引关系：`parent(i) = (i-1)/2`，`left(i) = 2*i+1`，`right(i) = 2*i+2`

## 🔍 详细解析

### C++ 标准实现
```cpp
// 下沉操作：将 arr[i] 下沉到正确位置
void siftDown(vector<int>& arr, int n, int i) {
    int largest = i;
    int left = 2 * i + 1;
    int right = 2 * i + 2;

    if (left < n && arr[left] > arr[largest])
        largest = left;
    if (right < n && arr[right] > arr[largest])
        largest = right;

    if (largest != i) {
        swap(arr[i], arr[largest]);
        siftDown(arr, n, largest);  // 递归下沉
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();

    // 1. 建堆：从最后一个非叶节点开始下沉
    // 最后一个非叶节点索引 = n/2 - 1
    for (int i = n / 2 - 1; i >= 0; i--) {
        siftDown(arr, n, i);
    }

    // 2. 排序：依次取堆顶交换到末尾
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]);       // 堆顶（最大值）放到末尾
        siftDown(arr, i, 0);        // 对剩余 i 个元素重新下沉
    }
}
```

### Csharp 版本
```csharp
public static class HeapSort
{
    public static void Sort(int[] arr)
    {
        int n = arr.Length;

        // 建堆
        for (int i = n / 2 - 1; i >= 0; i--)
            SiftDown(arr, n, i);

        // 排序
        for (int i = n - 1; i > 0; i--)
        {
            (arr[0], arr[i]) = (arr[i], arr[0]);
            SiftDown(arr, i, 0);
        }
    }

    private static void SiftDown(int[] arr, int n, int i)
    {
        int largest = i;
        int left = 2 * i + 1;
        int right = 2 * i + 2;

        if (left < n && arr[left] > arr[largest]) largest = left;
        if (right < n && arr[right] > arr[largest]) largest = right;

        if (largest != i)
        {
            (arr[i], arr[largest]) = (arr[largest], arr[i]);
            SiftDown(arr, n, largest);
        }
    }
}
```

### 建堆时间复杂度分析
直观理解：节点数随层数指数减少，每层调整高度有限。
- 精确分析：建堆总代价 = sum(h * n/2^(h+1)) = O(n)
- 不是 O(nlogn)！面试追问高频点

### 堆排序 vs 快排对比
| | 堆排序 | 快速排序 |
|--|--------|---------|
| 稳定性 | 不稳定 | 不稳定 |
| 空间复杂度 | O(1) | O(log n) |
| 最坏情况 | O(nlogn) | O(n^2) |
| 缓存友好度 | 差（非连续访问） | 好 |
| 实践中速度 | 较慢 | 较快 |

## 💬 面试官常见追问
- "建堆为什么是 O(n) 而不是 O(nlogn)？" -> 越靠近底层的节点下沉高度越小，详细数学推导
- "堆排序为什么在实践中不如快排？" -> 缓存不友好（父子节点内存不连续）、交换次数多
- "如何用堆实现优先队列？" -> push：插到末尾上浮；pop：取堆顶，末尾换到堆顶下沉

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：建堆从前往后做上浮。正确做法是从最后一个非叶节点 (n/2-1) 开始自底向下沉
- **误区**：排序部分写成 `for(int i=n-1; i>=0; i--)`。当 i=0 时数组只剩一个元素，不需要再交换和下沉
- **误区**：siftDown 中 largest 的比较没防越界。必须先判断 left < n 和 right < n
