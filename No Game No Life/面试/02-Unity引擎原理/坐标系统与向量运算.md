## 一句话结论（自测用）
> Unity 五大坐标系：世界(World)、局部(Local)、屏幕(Screen，左下角原点)、视口(Viewport，归一化0-1)、GUI(左上角原点)。点乘判夹角，叉乘判方向。四元数表示旋转，避免万向节锁。

## 标准答案（结构化、可背诵，2分钟内讲完）
1. **五大坐标系**：
   | 坐标系 | 原点 | 单位 | 用途 |
   |--------|------|------|------|
   | World Space | 世界原点 (0,0,0) | 世界单位 | 物体绝对位置 |
   | Local Space | 父物体 pivot | 世界单位 | 相对于父物体的偏移 |
   | Screen Space | 屏幕左下角 | 像素 | `Input.mousePosition`、触摸位置 |
   | Viewport Space | 屏幕左下角 | 归一化 (0~1) | 视口坐标 `Camera.ViewportToWorldPoint` |
   | GUI Space | 屏幕左上角 | 像素 | IMGUI 绘制 |

2. **点乘（Dot Product）**：
   - `Vector3.Dot(A, B) = |A||B|cos(theta)`
   - 结果 > 0：夹角 < 90 度（同向）
   - 结果 < 0：夹角 > 90 度（反向）
   - 结果 = 0：垂直
   - 应用：判断目标在面前还是背后（`Dot(forward, toTarget) > 0` 表示在前面）

3. **叉乘（Cross Product）**：
   - `Vector3.Cross(A, B)` 返回垂直于 A 和 B 的向量
   - 返回向量的方向用**左手定则**（Unity 是左手坐标系）
   - 应用：判断目标在左边还是右边（`Cross(forward, toTarget).y > 0` 表示在右边）

4. **四元数（Quaternion）**：
   - 表示旋转，避免**万向节锁**
   - 创建：`Quaternion.Euler(x, y, z)` / `Quaternion.LookRotation(direction)`
   - 插值：`Quaternion.Lerp`（线性）/ `Quaternion.Slerp`（球面线性，更平滑）
   - 旋转向量：`Quaternion * Vector3`（将向量按四元数旋转）

## 详细解析

### 坐标转换速查表
```csharp
// 世界 <-> 局部
transform.TransformPoint(localPos);  // 局部 -> 世界
transform.InverseTransformPoint(worldPos);  // 世界 -> 局部

// 世界 <-> 屏幕
Camera.main.WorldToScreenPoint(worldPos);  // 世界 -> 屏幕
Camera.main.ScreenToWorldPoint(screenPos);  // 屏幕 -> 世界

// 屏幕 <-> 视口
Camera.main.ScreenToViewportPoint(screenPos);
Camera.main.ViewportToScreenPoint(viewportPos);

// 世界 <-> 视口
Camera.main.WorldToViewportPoint(worldPos);
Camera.main.ViewportToWorldPoint(viewportPos);
```

### 点乘的经典应用
```csharp
// 1. 判断敌人在面前还是背后
float dot = Vector3.Dot(transform.forward, enemy.position - transform.position);
bool inFront = dot > 0;

// 2. 视角检测（视野角）
float angle = Vector3.Angle(transform.forward, toEnemy);
bool inViewCone = angle < 45f; // 45度视野

// 3. 减速曲线（越接近终点越慢）
speed = Mathf.Lerp(speed, 0, Time.deltaTime * 5f); // 常用 dot 结合
```

### 叉乘的经典应用
```csharp
// 判断敌人在左边还是右边
Vector3 cross = Vector3.Cross(transform.forward, toEnemy);
if (cross.y > 0) Debug.Log("Right");
else if (cross.y < 0) Debug.Log("Left");
else Debug.Log("Straight");
```

### 四元数为什么不会万向节锁？
欧拉角按顺序旋转（Y -> X -> Z），当中间轴转到 90 度时，第一轴和第三轴重叠（丢失一个自由度）。四元数直接用 4 个值表示任意朝向，不存在"顺序"和"重叠"问题。

### 欧拉角转四元数的限制
`Quaternion.Euler(90, 0, 0)` 和 `Quaternion.Euler(90, 90, 0)` 可能在不同路径下表示类似的朝向，这是欧拉角自身的多义性，不是四元数的问题。

## 面试官常见追问
- 点乘为什么能判夹角？（公式 `A dot B = |A||B|cos(theta)`，cos 的正负对应锐角/钝角）
- `Quaternion.Lerp` 和 `Slerp` 的区别？（Lerp 线性插值角速度不均匀，Slerp 球面插值角速度均匀）
- `transform.forward` 和 `Vector3.forward` 的区别？（forward 是物体的局部前方，Vector3.forward 是世界 Z 轴方向 (0,0,1)）
- Unity 是左手还是右手坐标系？（左手坐标系：X 右、Y 上、Z 前）

## 我曾经的误区 / 网上常见错答
- **错**："点积 < 0 表示在背后" —— 实际是夹角 > 90 度，不一定是正背后
- **错**："四元数很难懂，应该用欧拉角" —— 欧拉角用于人类理解和 Inspector 编辑，四元数用于计算和插值
- **错**："Screen Space 的 (0,0) 是左上角" —— Unity 的屏幕坐标左下角是 (0,0)，只有 GUI 坐标系是左上角
