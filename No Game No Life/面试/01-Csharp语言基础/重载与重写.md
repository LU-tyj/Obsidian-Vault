## 一句话结论（自测用）
> 重载（Overload）= 编译时多态，同方法名不同参数。重写（Override）= 运行时多态，子类用 override 重写父类 virtual/abstract 方法。核心区别：重载看参数类型，重写看实例类型。

## 标准答案（结构化、可背诵，2分钟内讲完）
1. **重载（Overload）**：
   - 同一类中，方法名相同，参数列表不同（类型/数量/顺序）
   - **返回值类型不同不足以重载**（Csharp 不允许仅返回值不同的重载）
   - 编译时绑定（Compile-time Polymorphism）
   - 示例：`void Attack()` / `void Attack(int damage)` / `void Attack(float range, int damage)`
2. **重写（Override）**：
   - 子类中，方法名、参数、返回类型完全一致
   - 父类方法标记为 `virtual` / `abstract`，子类用 `override` 重写
   - 运行时绑定（Runtime Polymorphism / Dynamic Dispatch）
   - 示例：`class Dog : Animal { public override void Speak() { ... } }`
3. **关键标志**：
   - `virtual`：标记可被重写，提供默认实现
   - `abstract`：必须被重写，不能有方法体
   - `override`：显式重写父类方法
   - `new`（方法隐藏）：不是重写，是隐藏父类方法，不参与多态
   - `sealed override`：重写后禁止孙类再重写

## 详细解析

### 方法隐藏（new）与重写（override）的关键区别
```csharp
class Parent {
    public virtual void Foo() => Console.WriteLine("Parent");
}
class ChildOverride : Parent {
    public override void Foo() => Console.WriteLine("ChildOverride");
}
class ChildNew : Parent {
    public new void Foo() => Console.WriteLine("ChildNew");
}

Parent a = new ChildOverride();
a.Foo(); // "ChildOverride" -- 多态，运行时看实例类型

Parent b = new ChildNew();
b.Foo(); // "Parent" -- 隐藏不是重写，编译时看声明类型
```

### 重载二义性问题
```csharp
void Method(int a, float b) { }
void Method(float a, int b) { }
Method(1, 2); // 编译错误：二义性，不知道调用哪个
```

### 重载解析规则（Csharp 规范）
编译器按以下优先级选择：
1. 完全匹配的参数类型
2. 隐式转换后可匹配的
3. 更具体的派生类型优先于基类型
4. 非泛型方法优先于泛型方法

## 面试官常见追问
- `override` 和 `new` 的区别？（override 是多态，运行时动态派发；new 只是隐藏，编译时绑定）
- 构造函数能不能重载？（可以，this() 链式调用）
- 运算符重载（operator overload）和普通方法重载有什么区别？（运算符重载必须是 static + public，至少一个参数是包含类型）
- 属性可以重写吗？（可以！和 virtual 方法一样用法）

## 我曾经的误区 / 网上常见错答
- **错**："重载就是同一个方法名字不一样" —— 重载的关键是参数列表不同，方法名必须相同
- **错**："new 关键字就是重写" —— new 是隐藏，不参与多态，面试经常作为陷阱题
- **错**："静态方法可以重写" —— 静态方法属于类，不可以重写，但可以用 new 隐藏
