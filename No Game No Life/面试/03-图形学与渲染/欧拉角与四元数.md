## 🎯 一句话结论（自测用）
> 欧拉角用三个旋转角度描述朝向，直观但会产生万向节锁（Gimbal Lock）——两个旋转轴重合时丢失一个自由度。四元数用四维向量表示旋转，不会万向节锁，插值平滑（Slerp），是游戏引擎内部的标准旋转表示。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **欧拉角**：
   - 三个角度 (roll, pitch, yaw) 围绕三个轴顺序旋转
   - 优点：直观，编辑器用起来方便
   - 致命缺点：**万向节锁**——当 pitch = ±90° 时，roll 和 yaw 轴重合，丢失一个旋转自由度，导致旋转"卡住"

2. **四元数**：
   - 结构：`q = w + xi + yj + zk`，其中 w 为实部，(x,y,z) 为虚部表示旋转轴
   - 表示绕单位轴 n 旋转 θ 角的旋转：`q = (cos(θ/2), n·sin(θ/2))`
   - 优点：无万向节锁、插值平滑（Slerp）、旋转组合简洁（乘法）、只有 4 个浮点数
   - 缺点：不直观，人难以直接理解和编辑四元数

3. **欧拉角转四元数**：
   ```
   q = Quaternion.Euler(yaw, pitch, roll)
   // 或者分别绕三个轴旋转后相乘
   q = q_yaw * q_pitch * q_roll
   ```

4. **Slerp vs Lerp**：
   - **Lerp**：线性插值，旋转速度不均匀（两端慢，中间快）
   - **Slerp**：球面线性插值，在四维球面上沿最短弧匀速旋转

## 🔍 详细解析

**万向节锁（Gimbal Lock）的直观理解**：
- 想象一个三轴万向架（gyroscope frame）
- 当第二个轴旋转 90° 时，第一个轴和第三个轴的旋转平面重合
- 此时改变第一个轴和改变第三个轴产生完全相同的旋转效果
- 你永远无法从这个姿态直接做某个方向的旋转——必须"绕路"

**反射向量的计算**（网易雷火高频）：
- 入射方向 I，法线 N（单位向量）
- 反射方向 `R = I - 2 * dot(I, N) * N`
- 推导：将 I 分解为平行 N 的分量和垂直 N 的分量，反射时平行分量取反、垂直分量不变

**旋转组合**：
- 矩阵：`R = Rz * Ry * Rx * v`（顺序依赖）
- 四元数：`v' = q * v * q^(-1)`（将向量 v 视为纯虚四元数）

## 💬 面试官常见追问
- "什么时候用欧拉角，什么时候用四元数？" -> 编辑器/用户界面用欧拉角（直观），引擎内部存储和运算用四元数
- "两个四元数相乘表示什么？" -> 组合旋转，q1 * q2 表示先做 q2 旋转再做 q1 旋转
- "四元数的 Slerp 是怎么实现的？" -> 在两个四元数的四维球面上按最短弧做球面插值，涉及 acos 和 sin 计算

## ⚠️ 我曾经的误区 / 网上常见错答
- 误区：Unity Inspector 中显示的是四元数。实际上是欧拉角，内部存储的是四元数
- 误区：避免万向节锁只要不用欧拉角就行。旋转矩阵也会遭遇万向节锁问题，只有四元数能完全避免
- 误区：反射向量的符号应该是 `R = 2*dot(N,I)*N - I`。这个公式等价于 `I - 2*dot(I,N)*N`，只是符号写法不同
