## 🎯 一句话结论（自测用）
> 标准二分 `while(l<=r)`，`mid=l+(r-l)/2` 防溢出。变形：找第一个 >= target（lower_bound）、找最后一个 <= target（upper_bound-1）。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **标准二分**：`while (l <= r)`，找到 target 返回，否则按大小调整 l/r
2. **lower_bound（第一个 >= target）**：`while (l < r)`，`nums[mid] >= target` 时 `r = mid`，否则 `l = mid + 1`
3. **upper_bound（第一个 > target）**：`while (l < r)`，`nums[mid] > target` 时 `r = mid`，否则 `l = mid + 1`

## 🔍 详细解析

### 模板一：标准二分（找到 target 的任意位置）
```cpp
int binarySearch(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // 防溢出
        if (nums[mid] == target)
            return mid;
        else if (nums[mid] < target)
            l = mid + 1;
        else
            r = mid - 1;
    }
    return -1;
}
```
适用：查找是否存在 target，返回任意匹配位置。

### 模板二：lower_bound（第一个 >= target 的位置）
```cpp
int lowerBound(vector<int>& nums, int target) {
    int l = 0, r = nums.size();  // 注意 r 初始化为 n
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] >= target)
            r = mid;         // 收缩右边界（包含 mid）
        else
            l = mid + 1;     // 收缩左边界（排除 mid）
    }
    return l;  // l == r，第一个 >= target 的位置
}
```

### 模板三：upper_bound（第一个 > target 的位置）
```cpp
int upperBound(vector<int>& nums, int target) {
    int l = 0, r = nums.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] > target)
            r = mid;
        else
            l = mid + 1;
    }
    return l;
}
```

### 常见二分变体速查
| 目标 | 模板 | 判断条件 |
|------|------|---------|
| 找到任意位置 | 标准二分 | `== target` |
| 第一个 >= target | lower_bound | `>= target` 时 r=mid |
| 第一个 > target | upper_bound | `> target` 时 r=mid |
| 最后一个 < target | lower_bound - 1 | 返回 lower_bound 前一位 |
| 找 target 范围 | [lower_bound, upper_bound) | 两个模板结合 |
| 旋转数组最小值 | 特殊二分 | `nums[mid] > nums[r]` 则 l=mid+1 |

### 面试场景题代码
**查找有序数组中大于某个数的第一个元素（面经 004_Q7）**：
```cpp
int firstGreaterThan(vector<int>& nums, int target) {
    // 等价于 upper_bound
    return upperBound(nums, target);
}
```

**旋转有序数组找最小值（LeetCode 153）**：
```cpp
int findMin(vector<int>& nums) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] > nums[r])
            l = mid + 1;  // 最小值在右边
        else
            r = mid;      // 最小值在左边（包括 mid）
    }
    return nums[l];
}
```

## 💬 面试官常见追问
- "为什么不用 `mid = (l + r) / 2`？" -> l+r 可能溢出 int 范围（当数组很大时）
- "二分查找只能在有序数组上用吗？" -> 可以用于任何具有单调性质的函数（如 sqrt、capacity check）
- "两种模板（while(l<=r) vs while(l<r)）的选择？" -> 找精确值用 l<=r，找边界用 l<r

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：边界条件 `l <= r` 和 `l < r` 混用。lower_bound 用 `l < r`，标准二分用 `l <= r`
- **误区**：lower_bound 中 `r = mid - 1`。应该用 `r = mid`（需要保留满足条件的元素）
- **误区**：`mid = l + (r - l) / 2` 在 `l < r` 的模板中可能死循环（l=0,r=1 时 mid=0）。这是正常的，因为 `l = mid + 1` 会推进
