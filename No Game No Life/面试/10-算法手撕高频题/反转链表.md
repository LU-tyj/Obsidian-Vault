## 🎯 一句话结论（自测用）
> 迭代：pre/cur/next 三指针，cur 指向前一个。递归：返回新头，cur.next.next = cur; cur.next = null。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. 迭代法：`pre=null, cur=head`，遍历时 `next=cur.next; cur.next=pre; pre=cur; cur=next`。返回 pre
2. 递归法：递归到最后一个节点作为新头，回溯时翻转指向
3. 时间复杂度 O(n)，空间 O(1)（迭代）/ O(n)（递归栈）

## 🔍 详细解析

### 迭代法（推荐面试手写）
```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* pre = nullptr;
    ListNode* cur = head;
    while (cur) {
        ListNode* next = cur->next;  // 保存下一个
        cur->next = pre;              // 当前指向前一个
        pre = cur;                    // 前指针后移
        cur = next;                   // 当前指针后移
    }
    return pre;  // pre 是新头节点
}
```
三个指针：pre（已反转部分的头）、cur（当前）、next（暂存下一个）。

### 递归法
```cpp
ListNode* reverseList(ListNode* head) {
    if (!head || !head->next) return head;  // 递归基
    ListNode* newHead = reverseList(head->next);
    head->next->next = head;  // 下一个节点指回当前节点
    head->next = nullptr;     // 当前节点断开（防止环）
    return newHead;
}
```

### Csharp 版本
```csharp
public ListNode ReverseList(ListNode head)
{
    ListNode pre = null, cur = head;
    while (cur != null)
    {
        ListNode next = cur.next;
        cur.next = pre;
        pre = cur;
        cur = next;
    }
    return pre;
}
```

### 进阶变体
**反转链表的前 N 个节点**：
```cpp
ListNode* successor = nullptr;  // 记录第 N+1 个节点
ListNode* reverseN(ListNode* head, int n) {
    if (n == 1) {
        successor = head->next;
        return head;
    }
    ListNode* last = reverseN(head->next, n - 1);
    head->next->next = head;
    head->next = successor;
    return last;
}
```

**反转区间 [m, n]**（LeetCode 92）：
```cpp
ListNode* reverseBetween(ListNode* head, int m, int n) {
    if (m == 1) return reverseN(head, n);
    head->next = reverseBetween(head->next, m - 1, n - 1);
    return head;
}
```

## 💬 面试官常见追问
- "递归版本的递归深度最多是多少？" -> 链表长度 n，递归栈深度 O(n)，可能栈溢出
- "如果链表太长怎么优化递归？" -> 改用迭代法 O(1) 空间
- "K 个一组反转怎么做？" -> 先反转 K 个，再递归处理剩余

## ⚠️ 我曾经的误区 / 网上常见错答
- **误区**：迭代法忘了保存 next。`cur->next = pre` 后 cur 的下一个节点丢失，必须先保存
- **误区**：递归法忘了 `head->next = nullptr`。会导致环（前两个节点互相指向）
- **误区**：返回值搞混。迭代返回 pre，递归返回 newHead
