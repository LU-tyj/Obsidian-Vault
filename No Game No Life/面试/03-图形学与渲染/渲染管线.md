## 🎯 一句话结论（自测用）
> 渲染管线是将3D场景数据转换为2D屏幕图像的一系列阶段，分为应用阶段(CPU)、几何阶段(顶点处理/裁剪/屏幕映射)和光栅化阶段(片元生成/测试混合)，是图形学面试第一必问题。

## ✅ 标准答案（结构化、可背诵，2分钟内讲完）
1. **应用阶段（CPU）**：准备好渲染所需的网格、纹理、材质、灯光、摄像机数据，设置渲染状态，发起 DrawCall 提交给 GPU。
2. **几何阶段（GPU 顶点处理）**：
   - 顶点着色器：将顶点从模型空间经 MVP 矩阵变换到裁剪空间
   - （可选）曲面细分/几何着色器：增减顶点、修改图元
   - 裁剪：去掉视锥体外的图元
   - 屏幕映射：将裁剪坐标映射到屏幕像素坐标
3. **光栅化阶段**：三角形设置 -> 三角形遍历（生成片元）-> 插值顶点属性
4. **片元处理阶段**：片元着色器计算颜色 -> 逐片元测试（裁剪测试 -> Alpha Test（如有）-> 模板测试 -> 深度测试）-> 混合 -> 写入帧缓冲区

完整公式：`模型坐标 -> 世界坐标 -> 观察坐标 -> 裁剪坐标 -> NDC -> 屏幕坐标`

## 🔍 详细解析

**MVP 矩阵变换**是实现坐标空间转换的核心：
- **Model 矩阵**：局部空间 -> 世界空间（包含平移、旋转、缩放）
- **View 矩阵**：世界空间 -> 观察空间（相机为原点）
- **Projection 矩阵**：观察空间 -> 裁剪空间（正交或透视）

**几何着色器 vs 曲面细分着色器**（网易追问高频）：
- 曲面细分着色器：在 GPU 上动态增加顶点，提高模型细节（如地形 tessellation）
- 几何着色器：接受完整图元（三角形/线段），可输出新图元（如将点扩展为 billboard），但几何着色器不能替代曲面细分——前者是改变图元数量，后者是在现有图元内按规则细分

**顶点着色器 vs 片元着色器**：
- 顶点着色器：处理每个顶点，负责坐标变换、逐顶点光照，输出插值数据
- 片元着色器：处理每个片元，负责逐像素颜色计算、纹理采样、逐像素光照

**不透明物体渲染顺序**：从前往后（利用 Early-Z 提前剔除被遮挡的片元）
**透明物体渲染顺序**：从后往前（保证正确的混合结果）

## 💬 面试官常见追问
- "几何着色器可以实现曲面细分着色器的功能吗？" -> 不能，几何着色器操作的是完整图元，没有 tessellation 的细分规则
- "一个三角形会走几次顶点着色器？" -> 每个顶点一次，共 3 次
- "顶点光照和像素光照分别在哪里做？哪个质量高？" -> 顶点着色器做逐顶点光照（Gouraud Shading），片元着色器做逐像素光照（Phong Shading），逐像素质量更高

## ⚠️ 我曾经的误区 / 网上常见错答
- 误区：把"渲染"等同于"画出来"。实际上渲染管线是一个严格的流水线，每个阶段有明确的输入输出
- 误区：认为几何着色器用处很大。实际上现代引擎已经很少使用几何着色器，它的性能较差，很多功能已被 compute shader 替代
